# 浏览器操作与恢复

## 能力发现

使用当前环境实际暴露的受控浏览器能力。开始前读取真实工具 schema 和当前页面，不假设固定 MCP 名称、配置格式或 DOM 选择器。

能力至少需要支持：

- 打开官方创作后台；
- 读取可见或可访问页面结构；
- 点击、输入、上传素材和导航；
- 在用户需要登录时保持交互页面；
- 打开草稿箱、内容列表或公开页面核验结果。

缺少任何完成当前动作所必需的能力时停止自动投递，交付人工步骤。

## 会话与账号

- 使用用户指定或项目明确声明的隔离持久化会话；
- 平台和账号之间不共享登录态；
- 不读取用户日常 Chrome、Edge 或其他浏览器 Profile；
- 不复制 Cookie、Token、密码、二维码和验证码；
- 登录后从页面可见信息核对账号，无法区分账号时停止；
- 同一平台会话一次只允许一个任务使用；被占用时不强制解锁。

首次登录、验证码、双重验证、账号选择、协议确认和风险处理必须由用户本人完成。

## 页面操作

1. 从平台官方入口进入创作后台。
2. 读取当前页面，识别新建、草稿和内容管理入口。
3. 先识别标题、正文和目标动作控件，再识别封面、图片、摘要、分类和标签。
4. 不操作含义不清、不可逆或超出授权的控件。
5. 填充后回读关键字段，不以输入动作成功代替页面内容确认。
6. 保存或发布后离开编辑器，从草稿箱、内容列表或公开页面重新核验。

平台变化时重新读取页面结构。渠道 reference 只记录稳定字段和确认节点，不保存易失效选择器。

## 幂等与恢复

- 新建前查询同账号下是否已有相同标题或用户指定目标；
- 同一动作只执行一次；
- 保存、跳转或发布结果不明时，先查询目标是否已经存在；
- 确认不存在后才允许在用户授权范围内重试；
- 修正现有草稿时覆盖同一目标，不创建副本；
- 发现重复候选且无法判断时停止，由用户选择。

不要结束未知浏览器进程、删除锁文件、清空会话、重置账号或删除草稿来恢复流程。

## 安全记录

只记录平台、非敏感账号标识、阶段、时间、状态、公开地址和可复核页面证据。截图包含二维码、个人信息或后台敏感数据时不写入发布包或通用日志。
