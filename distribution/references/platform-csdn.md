# CSDN 分发

只处理已经通过开发者内容准入门禁的 CSDN 技术文章。

## 投递前

- 文章 `platform` 为 `csdn`；
- 标题、正文、封面及必要技术图片齐全；
- 环境、版本、代码、命令、验证范围和未验证项已经在文章中准确区分；
- `content_attribution`、分类和标签只有候选值时，投递前由用户或当前平台规则确认。

## 编辑器处理

- 不渲染 front matter，正文从导语开始；
- 使用平台原生 Markdown、代码块、标题锚点和自动目录；
- 标准长文阅读提示转换为原生 Markdown 斜体行；样式不保留时退回普通文本行，不删除提示；
- 不手写与自动目录重复的目录，不复制公众号富文本样式；
- 信息图后的 `图注：` 使用平台稳定支持的 Markdown 弱化样式，并保持与图片相邻；
- 保持代码语言、缩进、换行以及环境、命令和结果说明的相邻关系；
- 分类、标签、内容归属和封面按当前页面字段填写；字段变化或归属不明时停止。

## 核验

- 从草稿箱重新打开，核对标题、长文阅读提示、正文首段、目录、代码、图片、图注、分类、标签和归属；
- 逐图核对图注只出现一次、紧邻对应图片且视觉弱于正文；
- 检查长代码、表格或图片在真实阅读宽度下没有破坏技术语义；
- 草稿授权不包含公开发布、付费设置或其他推广动作；
- 公开发布后核对公开地址、账号、标题、代码关键位置和发布时间。
