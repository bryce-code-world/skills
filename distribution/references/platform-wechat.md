# 微信公众号分发

只处理微信公众号标准文章，不处理小绿书、图片消息或其他形态。

## 投递前

- 文章 `platform` 为 `wechat`；
- 标题、摘要、封面和正文图片齐全；
- 正文没有 H1、围栏代码、引用块、Markdown 表格、ASCII 排版和横向滚动结构；
- 用户已确认目标公众号，页面能够显示可核对的账号名称；
- 默认动作是保存草稿，群发、发布、定时和提交审核不属于草稿授权。

## 编辑器处理

- 使用 [payload-preparation.md](payload-preparation.md) 的原生脚本把 Markdown 映射为移动端稳定富文本，不渲染 front matter；
- 正文从导语开始，使用普通深色标题、自然段、正文级编号段落、图片和少量强调；
- 标准长文阅读提示映射为 13px 浅暖色提示块，可带窄暖色左边线和小内边距；它弱于导语和正文标题，不作为新的入口卡片；
- 重点加粗只消费文章中已经确认的 `**语义重点**`，分发阶段不得临时决定新的重点；
- 原生列表在真实预览中出现字号缩小或行高压缩时，必须使用正文级编号或项目段落，不接受导入器默认列表样式；
- 二级标题保持左对齐、深色加粗和足够的前后留白；允许一条窄暖色边线，不使用色块、卡片或居中课程标题；
- 默认不生成目录，不接受导入器产生的大面积蓝底标题块；
- 上传指定封面和正文图片，分别保留替代文字和可见图注；图注使用 13px 灰色居中样式并紧邻图片，不把 `alt` 显示为图注；
- 平台要求摘要、原创声明或其他账号字段时，按发布包已有信息填写；缺失时停止或转人工，不自行声明。

## 核验

- 从草稿箱重新打开目标；
- 核对标题唯一、正文首段、标题层级、段落、图片和摘要；
- 使用真实预览检查手机宽度、首屏、长文阅读提示、换行、留白、图片文字、目录和蓝底标题块；
- 抽查正文、二级标题和列表项的实际字号、行高、对齐与段间距；列表项必须与正文同字号、同一行高区间；
- 逐图核对图注内容、顺序、唯一性、邻接关系和次级视觉层级；图注进入普通正文或与图片分离时不得标记排版通过；
- 没有真实预览时只能报告草稿已保存，不能报告排版已通过；
- 公开发布后核对公开地址、公众号账号、标题、正文关键位置和发布时间。
