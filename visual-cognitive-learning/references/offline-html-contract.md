# 离线单 HTML 契约

## 一、文件边界

最终产物只有一个 `.html` 文件，并且：

- 包含完整的 `<!doctype html>`、`html`、`head` 和 `body`。
- CSS、JavaScript、SVG、数据、图标和必要资源全部内联。
- 通过 `file://` 直接打开，不需服务器、安装、账号或网络。
- 不依赖相邻的 CSS、JavaScript、图片、字体或数据文件。
- 页面关闭后不依赖外部状态才能重新使用。

## 二、禁止项

- 不使用外部 `src`、样式表、字体、图片、模块导入或 iframe。`data:` 内联资源允许。
- 不调用 `fetch`、`XMLHttpRequest`、`WebSocket`、`EventSource`、`sendBeacon` 或其他网络能力。
- 不使用 `eval`、`new Function` 或字符串拼接执行来源内容。
- 不将学习内容、用户输入或隐式跟踪数据写入本地存储。
- 不嵌入密钥、Token、Cookie、完整原文、绝对本地路径或隐藏业务数据。

## 三、页面结构

默认顺序：

1. 简短标题和唯一学习目标。
2. 第一屏内的主学习对象。
3. 紧邻对象的必要控件和当前状态。
4. 随操作更新的解释、公式、数值或关系提示。
5. 边界、异常、适用条件和来源说明。

视觉形式从主题推导，不套用固定配色、卡片或仪表盘。控件名称用学习者能够识别的动作，不使用实现术语。

## 四、可用性与无障碍

- 使用语义 HTML、原生按钮、输入、选择器和显式标签。
- 支持鼠标、键盘和触摸；保留可见焦点，不打乱原生 Tab 顺序。
- 从窄屏到桌面宽度不遮挡内容，不产生不可控的水平滚动。
- 色彩不是唯一状态编码；使用文字、图形或线型补充。
- 使用 `prefers-reduced-motion` 关闭非必要动画，并保留等价状态变化。
- 核心定义、规则和结论默认存在于 HTML，不依赖 JavaScript 才写入。
- JavaScript 初始化失败时，静态结构仍能说明主要关系、边界和错误。

## 五、输入与写入安全

- 校验用户输入的类型、范围、非数值和边界。
- 用户未指定文件名时，从主题生成简短可识别名称。
- 新文件先写候选再验证。目标已存在时使用新名称，或在获得明确授权后再替换。
- 获得替换授权后，仍先生成和验证完整候选，不边写边破坏旧文件。
- 提醒用户：HTML 是可复制文件，接收者能读取其中所有可见和内嵌内容。
