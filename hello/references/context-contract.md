# 最小协作上下文协议

用于为新 AI 或具体任务生成不落盘的个人背景摘要。它不是《个人全景档案》聚合索引或 `权威/` 的替代品，也不改变权威资料。

适用范围：当产出物会离开本地（提交远端、写入非私密目录或对外发布）时，本协议是强制前置分支，按 `remote-public` 处理；即使产出物留在本地，`local-private` 或 `trusted-collaboration` 也必须遵守主体核对、最小读取和用途授权。下面的公司/项目/收入/健康/家庭排除清单是离开本地时的默认硬边界，不把本地授权误扩展为对外授权；`clone-sandbox` 仍需单独授权并保持模拟边界。

## 必需元数据

- 用途：哪个 AI、哪个任务或哪类协作。
- 主体与受众：目标包的 `package_id`、`subject_id`、资料所有者/`owner` 和接收方/`audience`；读取前核对它们与本次任务一致。
- 生成时间和资料最近确认时间。
- 允许使用的资料范围。
- 使用期限或失效条件。

旧 schema 资料没有机器可校验的主体 manifest，只能在一次性迁移时由用户明确确认资料根目录、主体、所有者和接收方；适配器不会替宿主完成主体隔离。正式目标包中，宿主必须拒绝缺少或不匹配 `package_id`/`subject_id`/`owner`/`audience` 的读取请求。

目标包可由宿主注入上述包级元数据，或先读取只含以下最小字段的 metadata-only manifest：`package_id`、`subject_id`、`owner`、`audience`、`layout` 和 `schema_version`/`layout_version`。manifest 不得包含声明、事件、决策、候选、原始表达或其他个人资料内容；这一步不算生成上下文。旧 schema 没有该 manifest 时，仅可在迁移阶段让用户明确提供并核对主体、所有者、根目录和受众。若两者都无法取得，协议在任何内容读取前暂停，不得用默认路径、文件名或整篇档案猜测主体。

读取限制：目标适配器的 `status` 和 `record-disclosure` 仍可能为校验而受控读取资料包元数据、进度、候选和日志；`record-disclosure` 不是 metadata-only 入口。远端分支若没有宿主注入或目标 metadata-only 状态来源，必须在读取个人正文前暂停，不能把调用 `status`/`record-disclosure` 当作已经满足最小读取协议。

## 生成前判定清单（强制）

1. 主体和受众：先确认包级身份元数据、资料所有者、接收方和允许用途；任何不匹配都停止读取。
2. 产出物去向：是否会提交远端、写入非私密目录或对外发布；任一为“是”都不得直接读取整篇《个人全景档案》或整套 `权威/`。
3. 读取范围：先列出本任务必需的主题、声明/事件/决策 ID 和来源位置，只读取这些范围；默认从聚合索引速览层开始，未列入范围的原始访谈、历史版本和待确认候选不读取。
4. 抽象化要求：对 `remote-public` 或任何会离开本地的输出，不写公司名、项目名、收入、健康细节或家庭责任；改写为可支持当前判断的能力、约束、资源或协作偏好，无法安全抽象时删去。`local-private`/`trusted-collaboration` 仍按最小范围和用途授权处理，不得把本地许可推定为对外许可。不要把自传或克隆视图中的叙事直接当作事实。
5. 结论缺失：如果最小范围抽不出可靠结论，明确标为“未知/待确认”，向用户请求是否扩大范围或补充信息；不得用整篇档案兜底，也不得把 AI 推测写成事实。

## 允许内容

只选择当前任务确实需要的：

- 当前目标和现实约束。
- 与任务相关的已确认事实及来源位置。
- 用户已确认的协作偏好。
- 与判断直接相关的资源、能力证据和未知冲突。
- 经单独授权的 AI 协作或克隆规则；克隆用途必须标为 `clone-sandbox`，不能默认沿用普通协作授权。

`clone-sandbox` 的每次输出还必须带机器/文本标记 `simulation=true`、源版本、受众和“无签名、无身份、无对外行动权限”；P2 生成器尚未实现前只能人工生成并明确这是模拟，不得声称已经具备可直接克隆或代行能力。

每条重要内容标注事实、本人理解、外部证据、AI 假设或未知冲突，并保留确认时间或有效期。AI 假设不能在上下文中改写成事实。

## 默认排除

- 与任务无关的健康、关系、经济、身份和第三方信息。
- `待确认信息.md` 中尚未审核的候选。
- 密码、验证码、密钥、支付凭据、完整证件号和精确住址。
- 只服务当前一次操作的临时参数，除非用户明确要求纳入。

## 输出与交付

先展示主体/受众、将纳入的范围和敏感排除项，再生成摘要。默认只在当前会话返回，不写入个人资料空间、不上传外部服务、不自动共享给其他 AI。用户要求扩大范围时重新按最小披露原则筛选。任何要求用克隆视图签名、冒充本人或代为对外发送的动作都必须拒绝并要求单独授权。

## 质量教训

整篇搬运只能复述“我做过什么”，答不出“我擅长什么”。最小上下文不只是隐私问题，也是质量问题：只带与任务相关、可追溯且经过抽象的证据，才能让协作方得出可用结论。
