## 状态定义

`not_started`、`signals_only`、`partial`、`confirmed_minimum`、`deepened`、`stale`、`conflicted`、`declined`、`not_applicable`。

基线收口只看“基线必答”行：达到 `confirmed_minimum`，或用户明确选择 `declined` / `not_applicable`，且没有阻塞冲突即可。可长期补充项不阻塞收口。`confirmed_minimum` 的具体字段和证据要求由 P1 冻结；基线完成不代表 17 个主题的 `coverage_complete` 已完成。

## 最低覆盖锚点（当前草案）

这些锚点让访谈知道何时有了可追溯的起点，不是量表，也不要求一次完成。除健康等敏感主题外，达到 `confirmed_minimum` 通常需要一条用户确认的 `Claim`、`Event` 或 `Decision` 及其来源；用户明确 `declined` / `not_applicable` 可关闭该主题。详细字段、证据等级和模型版本在 P1 冻结，下面的文字是目标包实例应保留的当前草案：

| 主题 ID | 最低覆盖锚点（草案） |
|---|---|
| `situation` | 当前处境、角色、语言/用途、核心约束、现实责任、近期目标 |
| `chapters` | 人生章节时间锚点、主题、至少一个转折或明确未知边界 |
| `environment` | 成长/当前环境及对行动的影响边界 |
| `learning` | 学习路径、知识结构、有效学习方式及来源 |
| `work` | 重要角色、产出/结果、适用时间及来源 |
| `capability` | 能力、适用条件/边界，至少一条 `evidence_ref` |
| `health` | 用户愿意披露的功能、精力、恢复边界或明确拒答；不做诊断 |
| `economy` | 安全感、可调用资源和风险边界；金额可省略 |
| `relationships` | 本人的关系角色、支持、责任、边界；第三方最小化 |
| `behavior` | 跨场景可观察模式、触发条件和例外，避免人格定型 |
| `emotion` | 反复情绪/压力模式、应对和可持续边界，按用户选择深度 |
| `worldview` | 信息来源、判断依据及相信/不确定边界 |
| `values` | 价值优先级、冲突和不可接受边界，或带权衡的决策 |
| `turning-points` | 事件、选择、结果及当时/现在理解；敏感内容可用影响摘要 |
| `resources` | 时间、工具、渠道、支持、环境资源及限制 |
| `future` | 愿景/目标、关键假设、下一步验证或复盘时间 |
| `ai-collab` | 提问、提醒、质疑、记忆、披露和纠错的可执行边界 |

每个主题可沿“定位 → 证据 → 意义/规则 → 变化复核”加深；`unknown` / `conflicted` 要有可追溯 ID，不能用空白伪装已覆盖。基线必答项在没有用户明确关闭前仍阻塞收口。
