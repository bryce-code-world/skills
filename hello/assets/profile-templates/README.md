# 个人资料空间

> 本目录保存本地私密个人资料。未经本人明确同意，不得上传、公开或向无关任务披露。

## 默认读取顺序

1. [个人全景档案](./个人全景档案.md)
2. 只有继续访谈时才读取[访谈进度](./访谈进度.md)。
3. 只有核验来源或理解变化过程时，再读取[资料索引](./资料索引.md)、[迭代日志](./迭代日志.md)、`原始访谈/` 和 `历史版本/`。

[待确认信息](./待确认信息.md)不是权威个人背景，只在集中审核时读取。

## 使用边界

- 《个人全景档案》是唯一权威综合资料。
- 事实、本人理解、AI 假设和未知冲突必须分开。
- 只使用当前任务必要的个人信息。
- 资料发生变化时记录来源、时间、版本和确认状态。
