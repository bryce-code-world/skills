# 个人资料空间

> 本目录保存本地私密个人资料。未经本人明确同意，不得上传、公开或向无关任务披露。

## 默认读取顺序

1. [个人全景档案](./个人全景档案.md) 的“速览层”（当前处境、核心约束、主要能力模式、下一步待确认）。
2. 只有任务需要详细依据时才读取同一文件的正文备查层。
3. 只有继续访谈时才读取[访谈进度](./访谈进度.md)。
4. 只有核验来源或理解变化过程时，再读取[资料索引](./资料索引.md)、[迭代日志](./迭代日志.md)、`原始访谈/` 和 `历史版本/`。

[待确认信息](./待确认信息.md)不是权威个人背景，只在集中审核时读取。

## 存量档案迁移（需用户确认）

对已有 v21《个人全景档案》只做“前置速览层”迁移：先复制到隔离临时目录，按正文已有内容提取当前处境、核心约束、主要能力模式和下一步待确认，逐条保留原章节来源标注；不改写、不删除、不合并正文。向用户展示四项速览草稿和差异，取得明确确认后，使用受控 `apply` 写入并生成历史快照和迭代日志；未确认或抽不出可靠结论时保持原档案不变。迁移后正文仍作为备查层，v21 原始版本可从 `历史版本/` 恢复。

## 使用边界

- 《个人全景档案》是唯一权威综合资料。
- 事实、本人理解、AI 假设和未知冲突必须分开。
- 只使用当前任务必要的个人信息。
- 资料发生变化时记录来源、时间、版本和确认状态。
