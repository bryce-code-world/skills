# 发布能力契约

本文件定义 `broadcast` 与下游发布入口之间的稳定契约。内容生成、事实判断、平台重构和本地验收仍由 `broadcast` 负责；MCP、Skill、CLI 或浏览器只是可选入口，不得反向改变发布包。

## 何时读取

只有用户明确要求投递，并给出目标平台、账号或登录环境、草稿边界和准确发布包后，才读取本文件并检查入口。

“帮我写”“生成发布稿”或“适配多个平台”不等于授权投递。安装组件、配置凭据、登录账号、上传素材、保存草稿和公开发布是相互独立的授权。

没有明确授权时：

- 不连接发布 MCP 或账号；
- 不读取或配置 Token、Cookie 和其他凭据；
- 不上传图片；
- 不保存草稿；
- 不公开发布。

## 入口能力

自动入口必须能够完成或明确拒绝以下能力：

```text
列出平台及登录状态
检查指定平台授权
提交标题、正文和已授权素材到指定平台草稿
返回请求是否被接受、是否有持久化草稿证据
说明失败阶段、可能产生的副作用和能否安全重试
```

逐平台记录字段能力：

```text
标题：支持 / 不支持 / 未确认
摘要：支持 / 不支持 / 未确认
正文：支持 / 不支持 / 未确认
正文图片：支持 / 不支持 / 未确认
封面：支持 / 不支持 / 未确认
代码块：支持 / 不支持 / 未确认
内容归属：支持 / 不支持 / 未确认
分类：支持 / 不支持 / 未确认
标签：支持 / 不支持 / 未确认
```

工具 schema 存在某个参数，只能证明入口接受该字段，不能证明平台已经应用。可以人工补充的字段必须在投递前列为人工处理项；正文或目标形态无法可靠承载时停止自动投递。

## 选择入口

按当前环境的真实可用性选择：

1. 优先使用已连接、具备结构化工具和明确返回状态的发布 MCP；当前已知首选实现是官方 Wechatsync MCP。
2. 没有可用发布 MCP 时，可以使用已安装且依赖组件已连接的官方 Wechatsync Skill 或 CLI。
3. 浏览器能力只用于查看真实草稿，或在用户直接操作和确认下补充缺失字段；不由 `broadcast` 选择它自主创建首份草稿，也不作为默认批量发布器。
4. 没有满足契约的自动入口时，交付人工发布包。

MCP 只规定 Agent 如何调用工具，不自动提供平台登录、Markdown 转换、图片上传和草稿保存。只有实现上述能力并通过当前检查的 MCP Server，才是发布入口。

选择 Wechatsync 后读取 [publishing-wechatsync.md](publishing-wechatsync.md)。其他供应者只有在来源可核验、当前工具 schema 可读取且能力满足本契约时才可使用；需要成为长期支持实现时，再增加独立供应者 reference。不得根据工具名称猜测能力和参数。

## 发布前交接

逐平台提供：

```text
平台：
账号或登录环境：
目标形态：
标题：
正文 Markdown：
标题结构检查：
封面：
共享正文插图：
平台适配素材：
四重验收：
授权动作：
已知人工处理项：
```

开始前确认：

- 入口及必要组件真实可调用；
- 目标平台已经登录；
- 文件路径和素材可读；
- 标题、正文和素材属于同一平台版本；
- front matter 的 `title` 是唯一发布标题，正文没有 H1，并已通过 [platform-markdown-contract.md](platform-markdown-contract.md)；
- 内容没有未解决的事实缺口或待确认项。

## 执行与验收

优先调用只读工具检查平台、授权和字段能力。入口支持 dry-run 或等价预览时，先确认正文直接从导语开始，再逐个平台单次提交。

即使入口支持多平台参数，也分别记录：

```text
平台：
入口与实现：
开始前登录状态：
提交内容版本：
动作：
结果：
草稿链接或记录：
失败原因：
是否可能已经创建草稿：
下一步：
```

入口返回成功只证明其明确返回的结果，不自动证明草稿字段完整或平台呈现正确。能够安全查看真实草稿时，检查标题是否只出现一次、正文是否从导语开始，以及摘要、代码块、图片、封面、内容归属、分类、标签和目标平台呈现。无法查看的字段标为“未确认”。

失败后不自动重复提交。重试前先查询或让用户检查草稿箱；无法确认幂等性时停止重试。

## 状态

| 状态 | 含义 |
|---|---|
| 已生成发布包 | 仅本地内容完成 |
| 预检通过 | 入口、登录和素材检查通过 |
| 预览通过 | 只完成 dry-run 或等价预览 |
| 已提交 | 入口接受请求，尚未确认草稿 |
| 已保存草稿 | 平台出现可见草稿，或入口返回能够可靠定位的持久化草稿证据 |
| 草稿内容已确认 | 目标平台中的关键字段已经逐项确认 |
| 需人工处理 | 草稿存在，但仍有字段或呈现需要人工完成 |
| 待人工发布 | 发布包已完成，但没有满足契约的自动入口，需要用户首次创建草稿 |
| 已公开发布 | 只有用户明确授权且有公开页面证据时使用 |
| 失败 / 未知 | 记录准确阶段和是否可能产生副作用 |

不得把“已生成发布包”“已提交”“已保存草稿”“草稿内容已确认”和“已公开发布”混为一谈。

## 安全与降级

- 不在日志、文档或回复中回显 Token、Cookie 和凭据；
- 不替用户创建或修改登录凭据；
- 不把草稿链接误报为公开链接；
- 不因一个平台成功而假定其他平台成功；
- 不在 `broadcast` 中复刻登录、图片上传、平台 API、重试或发布脚本。

未获授权、入口不可连接、登录失效、字段能力不足、结果无法判断，或者新增配置尚未获授权时，停止对应平台自动投递并交付人工发布包。降级不影响已经完成的内容产物。
