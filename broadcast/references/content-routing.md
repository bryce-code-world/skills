## 建立三层内容画像

按顺序建立：

```text
一个全局内容任务
    ↓
可用、缺失与禁用材料
    ↓
每个平台一个主导文章原型
```

内容任务回答“读者主要要发生什么变化”。材料画像回答“底稿允许用什么完成变化”。平台主导原型回答“当前平台怎样组织这些材料”。题材名称、章节数量、术语密度和篇幅占比不能代替这三项判断。

## 确定全局内容任务

只选择一个：

| 内容任务 | 识别依据 | 主要目标效果 |
| --- | --- | --- |
| 知识解释 | 读者需要看懂概念、机制、关系或变化 | 正确理解并形成可迁移的认知模型 |
| 观点论证 | 读者需要获得判断依据、修正态度或辨析争议 | 能说明判断、理由、反方和边界 |
| 方法教程 | 读者需要在条件允许时完成任务或验证结果 | 能判断条件、选择动作、处理失败并验证 |
| 产品或创新传播 | 读者需要评估采用、实施或确认一种新方案 | 能说明价值、条件、风险和下一步 |

从底稿的公开价值和目标读者任务推导，不要求用户手工分类。两个候选会产生不同主要目标效果或不同文章主线时，停止定稿，只请求用户确认这一个选择。

“新闻、人物、案例、数据盘点、清单、故事”等是题材或材料形态，不单独成为内容任务。把它们继续映射到一个主要目标效果。清单只有在读者能够据此判断条件、执行动作并验证结果时，才属于方法教程。

## 记录底稿材料画像

只记录会改变写法的材料，不建立事实账本。分别写明：

- 可用材料：底稿真实包含、允许公开且证据强度明确；
- 缺失材料：目标效果需要但底稿没有；
- 禁用材料：涉及隐私、版权、未核实结果、虚构经历或用户明确排除。

从以下材料类别中选择实际存在的项：

- 事实与机制；
- 数据、实验或外部证据；
- 条件、步骤、失败路径和验证方式；
- 候选方案、选择依据、取舍和代价；
- 真实经历、动作、结果和判断变化；
- 场景、案例、反例、风险、未知和适用边界。

缺失与禁用材料不能进入标题、封面、开头、正文、结尾、图片和第一人称。样本研究只能校准表达机制，不能补齐底稿材料。

## 选择平台主导原型

每个平台只选择一个主导原型：

| 主导原型 | 底稿必须支持的推进关系 |
| --- | --- |
| 问题解释 | 可观察现象 → 常见误判 → 机制 → 后果与判断 |
| 观点论证 | 命题 → 理由与证据 → 反方或限制 → 适用判断 |
| 方法分享 | 使用条件 → 关键动作 → 失败路径 → 验证方式 |
| 能力演化 | 已有能力 → 暴露问题 → 新能力产生 → 新能力边界 |
| 认知变化 | 原判断 → 真实触发材料 → 判断变化 → 新判断影响 |
| 真实经验复盘 | 真实目标与处境 → 动作和结果 → 取舍 → 可迁移结论 |

优先选择能够最完整、最可信地完成主要目标效果的材料链。平台阅读任务可以改变原型选择，但不能创造底稿没有的推进关系。

材料不足时执行降级或停止：

- 没有真实观察、动作、结果或判断变化时，禁用认知变化和真实经验复盘；
- 方法教程缺少适用条件、失败路径或验证方式时，缩小为知识解释或请求补充；
- 产品或创新传播缺少采用价值、条件、风险或下一步时，缩小为知识解释或观点论证；
- 观点论证缺少理由、反方或边界时，缩小观点强度或请求补充；
- 技术文章缺少环境、版本或验证结果时，如实标记未知、示例或待验证，不改写为实测。

## 裁决混合内容

先按读者最终需要完成的变化选择全局内容任务，再按平台最完整的材料链选择主导原型。其他原型只能作为局部机制，不能开启第二条主线。

不要按材料数量投票。案例很多不等于经验复盘，步骤很多不等于方法教程，表达鲜明不等于观点论证。删除某个候选后，如果主要目标效果仍然成立，就把它降级为局部机制；如果两个候选都会改变文章成立方式，停止并请求用户确认。

## 叠加平台规则

全局内容任务、材料画像、事实强度和主要目标效果跨平台保持一致。平台主导原型可以不同。

平台只调整标题机制、封面模式、开头入口、解释密度、作者距离、代码呈现、结尾出口和格式。平台覆盖必须守住以下边界：

- 知乎不得把知识解释强改为观点站队；
- 掘金不得补造候选方案和工程取舍；
- CSDN 不得为可复现结构虚构环境、步骤和运行结果；
- 公众号不得为对象感虚构个人经历。

## 向下游交接

把以下结果写入 `00-广播任务总结.md`：

```text
内容任务：
底稿可用材料：
底稿缺失与禁用材料：
主要目标效果：
各平台主导文章原型：
```

标题、封面、开头、正文和结尾必须共同消费这些字段。平台层不得脱离任务总结重新猜测内容任务或材料边界。

## 执行内容路由门禁

生成平台稿前检查：

1. 是否只有一个全局内容任务和一个主要目标效果；
2. 内容任务能否追溯到底稿公开价值和目标读者任务；
3. 可用、缺失与禁用材料是否清楚，是否存在把缺失材料当作可补写项的情况；
4. 每个平台是否只有一个主导原型，且底稿能够支持完整推进关系；
5. 局部机制是否仍服务同一主线；
6. 平台规则是否只改变呈现，没有偷换内容任务、材料或事实强度。

任一项失败时返回内容画像修正。需要新增底稿事实、案例、经历、数据、方案或结果才能通过时，缩小内容任务或请求补充，不进入平台转写。
