# 传播关系契约

本文件只定义 `broadcast` 必须推导的传播关系。具体用词、口语、网络用语、句段节奏、读者往返和去模板化由 `$writing-style` 的 [relationship-and-voice.md](../../writing-style/references/relationship-and-voice.md) 实现。

## 为什么需要关系契约

同一事实由谁说、对谁说、保持多远距离，会影响读者是否愿意继续理解和接受。关系契约让标题、封面、开头、正文和结尾处于同一个可信说话关系中，但它不是文章结构，也不要求统一口语化。

关系契约必须来自底稿、目标读者、目标平台和话题风险。没有真实经历时仍可以建立说话位置，但不能补造亲历、身份、情绪和账号关系。

## 推导输入

- 作者在底稿中已经拥有的事实、判断、取舍和边界；
- 目标读者已有认知、关键缺口和最可能的困惑或反驳；
- 文章主要目标效果和入口承诺；
- 平台关系、阅读场景和话题后果；
- 用户明确指定的作者身份、风格和禁区。

## 契约结构

写入 `00-广播任务总结.md`：

```text
作者说话位置：凭什么谈、真正关心什么、采用什么判断、承认什么边界
读者关系：同行讨论 / 经验引导 / 共同观察 / 专业解释
对话距离：亲近 / 适中 / 克制
情绪温度：冷静 / 温和 / 鲜明
口语边界：稳定日常表达 / 少量平台口语 / 禁止戏谑
需要回应的读者反应：困惑、直觉、反驳、担忧或选择压力
可用内容载体：底稿已有场景、动作、对比、例子、作者判断或明确的通用假设
```

契约只描述传播所需关系，不预写口语、金句、反问、比喻和固定句式。

## 推导规则

1. 先确定作者能够真实站立的位置，再选择关系类型。
2. 读者关系服务主要目标效果，不以平台刻板印象代替读者判断。
3. 对话距离随读者熟悉度和风险调整；陌生读者与严肃话题默认更克制。
4. 口语边界只规定允许程度，不指定具体网络用语。
5. 需要回应的读者反应只选择主线上的真实断点，不把全文设计成自问自答。
6. 可用载体必须能追溯到底稿或明确标记为通用假设。

## 平台调整

- 公众号可以更亲近，强调持续阅读和关系沉淀；
- 知乎以命题讨论和共同推理为主，保持适中距离；
- CSDN 以问题解决和专业解释为主，关系更克制；
- 掘金可以保留工程同行之间的判断与取舍，但不虚构项目经历。

平台可以调节距离和温度，不能改变作者身份、核心立场和人格。

## 交给 Writing Style

写作前把关系契约、内容内核、主题、平台、风险和不可改变项交给 `$writing-style`。它负责形成本次关系与风格说明，并在完整平台稿和格式处理后分别校准语言实现。

`broadcast` 不回收 Writing Style 的语言实现规则，也不在本文件重复定义口语选择、具体场景、节奏变化和正向声音门禁。

## 验收

- 说话位置能由底稿或用户确认内容支持；
- 读者关系与目标效果、平台和话题风险一致；
- 标题、封面、开头、正文和结尾没有突然切换关系距离；
- 关键读者断点已经进入契约，但没有机械安排回应次数；
- 没有虚构经历、假装熟络、情绪表演和口癖配额；
- Writing Style 能根据契约完成语言实现，而不需要 Broadcast 预写具体措辞。

研究依据与适用边界保留在 [communication-effects.md](communication-effects.md) 和 Writing Style 的 [relationship-and-voice.md](../../writing-style/references/relationship-and-voice.md)，不在此重复展开。
