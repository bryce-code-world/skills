# 关系与声音工程

每次把内部底稿转成公开长文前读取。它负责把“传播给谁”进一步落实为“谁正在对谁说话”，让标题、开头、正文和结尾不仅可理解，也形成稳定、可信的作者—读者关系。

它不负责模仿具体作者，不要求编写个人故事，也不把网络用语当成人味。语言层实现与身份保护交给 `$writing-style`。

## 为什么单独设计

文章可以事实正确、结构完整、术语通俗，却仍像一份匿名说明书。常见原因不是口语词太少，而是：

- 看不出说话者为什么关心这个问题、采用什么判断；
- 只向“用户”输出信息，没有回应一个具体读者正在经历的困惑；
- 每节都用同一套定义、解释和总结，作者与读者之间没有真实来回；
- 为了显得亲切批量加入“说白了”“别急”“懂的都懂”，反而形成伪人类化。

关系与声音工程补的是传播关系，不是装饰语气。

## 建立关系契约

从底稿、读者模型、平台和风险中推导：

```text
作者说话位置：凭什么谈、真正关心什么、采用什么判断、承认什么边界
读者关系：同行讨论 / 经验引导 / 共同观察 / 专业解释
对话距离：亲近 / 适中 / 克制
情绪温度：冷静 / 温和 / 鲜明
允许的口语：稳定日常表达 / 少量平台口语 / 禁止戏谑
需要回应的读者反应：困惑、直觉、反驳、担忧或选择压力
可用的具体载体：底稿已有场景、动作、对比、例子、作者判断或可靠假设
```

作者说话位置必须来自底稿和用户已经确认的观点。没有真实经历时，可以使用“本文采用什么判断”“这个误区为什么值得拆开”“这里需要保留什么边界”，不能补造“我最近遇到”“我身边有人”。

关系契约进入 `00-广播任务总结.md`，各平台直接读取。平台可以调节距离和语气，不能把同一作者改成不同人格。

## 用共同语言建立对象感

先识别读者能够共同看见的现象、动作、代价或问题，再引入准确名称。不要用作者熟悉的抽象词测试读者是否“够专业”。

优先顺序通常是：

```text
共同处境或可观察动作 → 通俗作用 → 准确术语 → 对选择的影响
```

“共同语言”不等于把术语换成口水话。准确术语仍然保留，但第一次参与推理前要完成解释。行话即使附带定义，也可能增加加工阻力；定义不能替代站在读者已有认知上组织表达。

## 让说话者真实出现

从已有材料中选择能够承载关系的表达，不要求每项齐全：

- **局部判断**：明确本文怎样看一项取舍，以及依据和边界；
- **读者转身**：在读者最可能误解、反驳或担心的地方回应一次，不用假问句流水线；
- **微型场景**：用一个动作、对象或结果承载抽象机制；没有真实案例时使用明确的通用假设，不伪装成亲历；
- **诚实边界**：承认哪些结论只适用于当前范围，哪些事情文章没有证明；
- **自然反应**：底稿确有惊讶、无奈、偏好或警惕时保留，不额外表演情绪；
- **局部比喻**：只在能够压缩关系时使用，并及时回到准确概念。

这些表达服务内容推进。不能为了证明“有人味”，强迫每节出现一次作者判断、反问、比喻或短句。

## 控制口语与网络用语

口语的作用是降低对话距离、压缩共同反应或缓解抽象信息，不是制造流行感。

使用前同时检查：

1. 目标读者是否熟悉这种表达；
2. 作者与读者是否已经建立足够关系；
3. 平台是否允许这种亲近程度；
4. 话题后果是否允许幽默和戏谑；
5. 这句话是否承担了判断、节奏或关系功能。

删除一句口语后，意思、节奏和关系都不受影响，通常可以删除。优先使用寿命更长的日常口语；“炸裂、封神、破防、666”等强时效表达只有在作者稳定声线、受众和语境都支持时才使用。

非正式语言并非总能增加信任。面对陌生读者、严肃主题或尚未建立的作者关系，过度熟络可能适得其反。

## 让节奏服从信息重量

- 重要机制允许展开，过渡可以很短；
- 具体场景之后可以停一下，不立即补一段标准总结；
- 判断已经成立时直接往前走，不在每节末尾再完整收口；
- 句段长短来自信息轻重，不靠随机碎句、感叹号和破折号制造活泼；
- 小标题按真实问题关系命名，不为了整齐保持同样句式和长度。

## 交给 Writing Style

写作前把关系契约连同主题、风险、平台和内容内核交给 `$writing-style`。完整稿形成后，要求它同时执行正向声音检查与去模板化编辑：

```text
说话位置是否可感知：
读者关系是否贯穿关键转折：
具体场景和抽象解释是否相互承接：
口语是否合适且有功能：
节奏是否由信息重量决定：
是否新增了不存在的经历、情绪或身份：
```

## 关系与声音门禁

它是横切门禁，不替代入口、第一屏、推进、最后一屏和效果五道传播门禁。

- 删除作者名和平台标记后，文章仍能看出一个稳定的说话位置，而不是匿名百科；
- 关键判断来自底稿事实、推理和取舍，不来自通用金句；
- 读者最可能卡住的地方得到回应，不是把全文写成自问自答；
- 抽象概念至少在关键处落到可观察动作、对象、后果或准确类比；
- 口语和网络用语符合受众熟悉度、关系距离、平台与话题风险；
- 段落节奏随内容轻重变化，没有复制同一章节模具；
- 没有虚构经历、假装熟络、情绪表演和口癖注入。

失败时先修复具体关系断点：恢复已有判断、补回通俗对象、重组机械段落或删除伪口语。不要全篇换成聊天语气，也不要把缺少材料的问题交给措辞掩盖。

## 研究依据与边界

- [Kelleher, Conversational Voice, Communicated Commitment, and Public Relations Outcomes](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1460-2466.2008.01410.x) 将会话式人声与信任、满意度、承诺和关系结果联系起来；它支持设计可感知的说话关系，不代表口语越多越好。
- [Liebrecht et al., The Relative Power of Negativity](https://dspace.library.uu.nl/handle/1874/412064) 的相关分类把信息个性化、非正式表达和邀请式修辞视为会话式人声的语言要素。
- [Gretry et al., Don't pretend to be my friend!](https://www.sciencedirect.com/science/article/abs/pii/S0148296317300255) 发现非正式语言的信任效果受熟悉度和适配感影响，支持设置口语适配门而不是统一口语化。
- [Shulman et al., The Effects of Jargon on Processing Fluency](https://journals.sagepub.com/doi/full/10.1177/0261927X20902177) 表明行话会降低加工流畅度，即使提供定义也可能产生阻力。
- [Audience design and common ground](https://pmc.ncbi.nlm.nih.gov/articles/PMC5813694/) 支持区分共同知识与说话者独有知识，并从听者视角组织表达。
- [Narrative fluency and persuasion](https://www.frontiersin.org/journals/communication/articles/10.3389/fcomm.2021.719615/full) 支持用连贯场景和因果序列降低加工阻力，但不要求知识文章虚构故事。

高传播样本只能校准机制，不能证明“人味”单独造成十万加。量子位、阮一峰、宝玉和少数派等样本中反复出现的，是具体对象先于抽象概念、作者局部判断、读者回应和不均匀节奏；各账号的强口语、梗和夸张不作为通用模板。
