# 传播效果与入口承诺

每次生成广播任务总结和平台稿前读取。用统一传播过程管理不同内容类型，不把“易于传播”缩减为标题吸睛，也不要求每篇文章都推动行动。标题的市场样本、进入理由和淘汰方法同时读取 [headline-engineering.md](headline-engineering.md)。

## 先确保信息能够被读者解码

传播不是把作者的原话完整送达，而是让目标读者按预期理解其中的含义：

```text
作者含义
    ↓ 按目标读者的共同认知编码
标题、封面、开头与正文
    ↓ 经过平台环境与语义噪声
读者解码
    ↓
实际理解、判断或行动
```

作者认识某个词，不代表读者会赋予它相同含义。面向普通大众时，默认使用大众有共识的简单语言；“听过一个术语”只说明读者可能认得这个主题标签，不等于已经能够用它建立准确理解。

区分术语的三种状态：

```text
能够识别名称：可以在标题或封面中点名，帮助读者确认主题
已经理解概念：可以直接参与正文解释和推理
尚未理解或容易误解：先建立通俗含义，再给准确名称
```

标题和封面可以把目标读者认得的术语作为“本文要解释的对象”，但不得要求读者先懂术语，才能明白文章与自己有什么关系、能获得什么。正文可以点名即将解释的对象；在该概念参与因果、比较和判断前，必须先完成通俗解释。

为关键概念检查：

- 目标读者是否已经按本文所需含义理解这个词；
- 它只是被点名的解释对象，还是已经被用作解释前提；
- 它的日常含义是否会把读者带向另一种理解；
- 暂时遮住术语名称后，剩余表达是否仍能说明它解决什么问题或起什么作用；
- 如果不能，是否已经先用熟悉现象、问题或通俗作用建立概念。

无法通过时，先改用共同语言建立含义，再给出准确名称；不靠括号翻译、英文大小写或术语堆叠冒充解释。

## 使用统一传播效果链

```text
接触 → 注意 → 理解 → 加工与接受 → 记忆与提取 → 判断或态度 → 行动与扩散
```

这条链描述受众处理信息时可能经过的环节，不是所有文章必须走完的固定漏斗。先根据底稿的公开价值确定一个主要目标效果：

| 内容任务 | 主要目标效果 | 通过表现 |
| --- | --- | --- |
| 知识解释 | 正确理解并形成认知模型 | 能解释核心关系，不只复述术语 |
| 观点论证 | 获得新的判断依据或改变态度 | 能说出判断、理由、反方和边界 |
| 方法教程 | 形成行动能力并愿意尝试 | 能判断适用条件、步骤和验证方式 |
| 产品或创新传播 | 采用、实施或确认 | 能说明采用价值、条件、风险和下一步 |

从底稿、目标读者和平台阅读任务推导主要目标效果，不要求用户手工选择传播学分类。无法判断且不同目标会改变文章主线时，才请求确认。

“心智迁移”是本 Skill 对认知、态度和行为效果的工作性总称，不把它宣称为传播学中的单一标准变量。它必须能够拆成读者共同认知、容易误解的概念、关键缺口和目标效果，不能停留在“影响用户心智”一类抽象口号。

## 建立最小迁移模型

为每个平台分别回答：

```text
目标读者是谁：
可用于识别主题的术语：
可直接参与理解的共同概念：
必须先解释或容易误解的概念：
最容易误解什么：
为什么愿意关注：
理解这篇文章的动机与能力：
关键认知缺口：
主要目标效果：
完成迁移的内容主线：
```

只保留影响本篇文章的最小信息。读者画像、年龄标签和兴趣清单不能替代认知起点与缺口。

没有真实案例时，允许完全依靠事实、机制和逻辑演化完成迁移。不得为了对象感或“活人感”虚构个人经历。

## 把入口视为第一段内容

标题、封面、开头和正文共同兑现一份入口承诺：

- 标题说明目标读者为什么值得进入；
- 封面帮助识别主题、对象和情绪基调；
- 开头立即承接标题与封面，建立继续阅读的理由；
- 正文完成承诺的解释、论证或方法交付；
- 结尾回收到主要目标效果，不机械要求关注、转发或行动。

标题和封面同时承担注意竞争、读者筛选、阅读承诺和理解框架四项任务。它们不是正文完成后的装饰，也不能脱离正文单独追求点击。

准确说明主题只是最低门槛，不等于具有传播竞争力。标题通常还要建立一个具体张力或读者损益，让读者知道为什么值得现在进入；只剩术语清单、概念分类或“全面介绍”的标题，应回到 [headline-engineering.md](headline-engineering.md) 重新生成机制不同的候选。

执行两遍入口设计：

1. 写正文前完成真实标题样本校准，确定入口张力、标题假设、封面信息任务和开头任务；
2. 正文完成后对照实际内容校准标题、封面和开头，必要时联动修改。

可以内部比较多个方向，最终发布包只保留通过验收的版本。标题或封面提高点击欲望，却夸大事实、偷换命题、虚构事件或无法由正文兑现，直接判定失败。

## 识别三段传播过程

```text
获得传播机会
平台环境 → 选题呈现 → 标题与封面 → 点击或停留

完成心智迁移
开头承接 → 理解 → 加工与接受 → 记忆 → 判断或行动

获得反馈放大
读完 → 收藏、评论或转发 → 平台反馈 → 更多曝光
```

平台既是通道，也是注意力竞争环境和反馈分发机制。共同稳定的是底稿事实、核心结论、主要目标效果和心智迁移方向；标题、封面、开头、内容密度、节奏和互动出口必须按平台独立处理。

本地发布包只能验收入口设计、承诺兑现和预期效果。真实点击、读完、收藏、评论、转发和后续分发只能在用户授权投递且能够读取平台反馈后评估，不得用内容判断冒充真实传播数据。

## 执行三段传播门禁

### 入口门

只提供标题和最终封面，不提供正文、底稿和任务总结，请测试读者回答：

1. 这篇文章在说什么；
2. 它主要写给谁；
3. 点开后预期获得什么；
4. 是否愿意点开，具体原因是什么。
5. 为什么愿意现在点开，标题中哪一项具体信息造成了这个决定。

测试结果与目标读者、入口承诺和事实强度不一致时，修改标题或封面后复测。

### 兑现门

提供完整平台稿，不提供内部底稿、写作讨论和自评结论，检查：

- 开头是否立即承接标题与封面；
- 正文是否持续完成同一承诺；
- 是否存在标题抬高、正文降级或中途换题；
- 结尾是否回收到主要目标效果。

### 效果门

让测试读者只依据终稿回答：

- 新理解了什么关系；
- 获得了什么判断依据；
- 哪些边界、反例或适用条件仍然成立；
- 如果文章要求行动，下一步是什么、怎样判断结果。

由 `broadcast` 把回答与主要目标效果和关键认知缺口比较。只会概括文章主题、复述术语或说“文章很清楚”，不能证明效果门通过。

优先使用没有参与写作的独立执行者。无法独立执行时使用隔离上下文自检，并在 `06-读者测试.md` 明确记录降级；不得把同一写作者的主观确认写成独立读者结论。

## 理论边界

本模型组合使用：

- [Lasswell 的传播 5W](https://sipa.jlu.edu.cn/__local/E/39/71/4CE63D3C04A10B5795F0108EBE6_A7BC17AA_34AAE.pdf)，界定传播者、信息、渠道、受众和效果；
- [Schramm 编码、解码与共同经验范围的模型概述](https://manifold.open.umn.edu/read/d188db4e-a87d-4657-8601-9d153dd1310b/section/04511818-4578-4b3b-a7b5-d234c53a33ee)，提醒发送者与受众的语言、背景和知识会影响意义能否按预期形成；
- [Hovland 与 McGuire 的信息处理阶段综述](https://www.asc.upenn.edu/sites/default/files/2021-07/e3eff4_a0897b66efa746c895850d30adc6fd67.pdf)，描述从接触、注意和理解到接受、记忆与行为；
- [精细加工可能性模型](https://richardepetty.com/publications/)，判断受众的思考动机与能力；
- [创新扩散模型](https://www.simonandschuster.com/books/Diffusion-of-Innovations-5th-Edition/Everett-M-Rogers/9780743222099)，只处理涉及采用、实施和确认的目标；
- [NCI 传播规划指南](https://www.cancer.gov/publications/health-communication/pink-book.pdf)，把受众起点、目标效果、信息、渠道和评估连接起来。

这些模型互相补充。不要把任一模型机械套成所有文章的固定章节或强制行动漏斗。
