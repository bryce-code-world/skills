# 读者连续性、心智迁移与冷读门禁

每次直接从内部底稿转写平台文章前读取。它负责让平台稿沿一条自然内容主线完成预定心智迁移，而不是把底稿目录换一种格式搬过去。

## 建立可解码语言基线

写提纲、标题、封面和开头前，先从目标读者模型中区分：

```text
可以直接使用的共同认知：
不能默认理解的核心概念：
容易按日常含义误解的词：
必须保留的准确名称：
```

只检查决定本文理解的少数核心概念，不建立庞大术语账本。面向普通大众时，默认选择大众有共识的简单语言；目标读者是专业人群时，可以使用该群体真正共享的术语，但不能把“可能听过”当作“已经理解”。

术语首次进入必须满足：

1. 先让读者遇到自己能识别的现象、问题或作用；
2. 即使暂时遮住术语名称，句子仍能表达这个概念是什么；
3. 再给出准确名称，并在后文稳定使用；
4. 日常含义与专业含义不同时，就近说清差异。

新概念不得成为解释它自身的前提。以上约束覆盖任务总结中的传播主线、标题、封面文字、摘要、提纲、开头、小标题、正文和图片，不只检查完整正文。

## 参考已有写作方法

用户要求参考现成自媒体 Skill、样文或写作方法，或者当前工作区有直接相关的公开长文方法时，写提纲前读取最多三个最相关来源。只提取可迁移机制，例如具体场景怎样进入、问题怎样推进、观点和解释怎样交替、偏离后怎样扣回主线。

读取本地 Skill 源文件只是方法研究，不等于调用该 Skill。不得继承或复制作者身份、经历、人格、标志性口癖、粗口、固定标题、固定结尾、点击诱导和平台凭据。

## 为每个平台选择文章原型

根据底稿材料和平台阅读任务，分别选择真实经验复盘、认知变化、问题解释、观点论证、方法分享或能力演化中的一个主导原型。各平台可以不同，但必须表达同一底稿中的事实、观点、条件、主要目标效果和作者身份。

传播主线可以是读者共同经历、能力演化、核心问题、判断变化或持续场景，不强制使用作者当前工作作为案例。案例和具体锚点必须服务主题；它们让读者先理解案例本身时，应删除或降级为局部说明。

能力演化类文章按“已有能力 → 暴露问题 → 新能力为何产生 → 新能力又带来什么问题”推进。它可以完全依靠底稿事实和逻辑演化成立；没有真实案例时不得改写成虚构的个人认知变化。

不得把底稿章节、术语分类或检查清单直接翻译成正文目录。每个概念都要回答“目标平台的读者走到这里为什么正好需要它”。

## 建立段落推进链

写每篇平台稿前，内部回答：

```text
读者此刻已经知道什么：
这一部分可以直接使用哪些共同认知：
上一部分留下了什么问题：
这一部分只新增什么：
依靠底稿中的哪项材料：
怎样扣回标题和传播主线：
下一部分为什么自然出现：
```

任一部分无法填写时，合并、移动或删除，不靠“接下来我们看”制造假转场。连续两个部分无法扣回传播主线时，视为主线丢失。

专业概念按“读者熟悉的现象或困难 → 通俗作用 → 准确名称 → 回到主线”进入。不得在读者尚未遇到问题时成组倾倒术语，不得只用另一个陌生术语解释新概念，也不得用图片首次介绍正文没有解释的核心概念。

## 连接入口承诺与正文

写正文前确认：

```text
主要目标效果：
关键认知缺口：
入口承诺：
标题假设：
封面信息任务：
开头怎样立即承接：
正文用哪条主线兑现：
结尾回收到什么判断或行动：
```

正文完成后反向检查。标题、封面或开头承诺了正文没有交付的收益时，降低承诺或补回底稿已有论证；底稿没有支撑时只能降低承诺，不能补造内容。

## 让第一人称承担证据

第一人称必须连接底稿或用户材料中真实存在的观察、动作、犹豫、取舍、判断变化或后果。只有“我后来发现”“我很认同”“我现在会”，但没有真实材料支撑时，只是语气外壳。

底稿没有真实经历时，直接清楚解释，不伪装成经验分享。不得为了“活人感”编造时间、地点、对话、情绪和结果。

## 执行入口隔离测试

先只拿“最终标题 + 最终封面”测试，不提供正文、内部底稿、任务总结和自评结论。让测试读者说明：文章在说什么、写给谁、点开后预期获得什么、是否愿意点开以及具体原因。

由 `broadcast` 将回答与目标读者、入口承诺和事实强度比较。吸引了错误读者、承诺模糊、封面与标题各说各话或依靠夸大建立点击欲望时，修改后复测。

## 执行平台隔离冷读

每篇平台稿完成语言、视觉和格式终检后，只提供最终平台稿和必要的读者角色，不向冷读过程提供内部底稿、任务总结、提纲、主要目标效果和自评结论。测试者先独立回答，再由 `broadcast` 对照目标效果和认知缺口判断。

冷读只回答：

1. 第一次遇到无法直接理解的词或句子在哪里，当时怎样理解；
2. 哪个概念出现时缺少前提，遮住术语名称后是否仍然知道它是什么；
3. 哪次转场只是换话题，没有承接上一个问题；
4. 标题、封面和开头的承诺是否由正文持续兑现；
5. 第一人称是否有材料支撑；
6. 图片是否引入正文没有教过的内容；
7. 读完后新理解了什么关系，获得了什么判断依据；
8. 哪些边界、反例和适用条件仍然成立；
9. 文章要求行动时，下一步是什么、怎样判断结果。

将证据写入 `06-读者测试.md`，至少记录测试对象、隔离方式、读者假设、入口回答、首次卡顿位置、效果回答、与目标效果的差距、修改动作和复测结论。发现核心概念无入口、主线中断、承诺未兑现、图片越权、第一人称空壳或认知缺口未跨越时，直接修正对应平台稿并重新冷读。

优先使用没有参与写作的独立执行者。无法独立执行时使用隔离上下文自检，并明确记录降级；同一写作者的主观确认不得标记为独立冷读。

没有执行这次冷读时，概念进入、读者理解、内容主线和传播效果只能标记为“未验收”，不得由作者侧主线检查推断通过。缩略提纲可以单独测试标题方向、概念进入或章节因果，但必须写清测试维度，不能声称已经验证完整文章的连续阅读和传播效果。

## 执行跨平台复核

四个平台完成后，从内部底稿重新检查：

- 是否表达同一事实和观点强度；
- 是否因平台压缩产生相互矛盾；
- 是否有平台新增底稿不存在的案例、经历、数据或结论；
- 是否保持同一作者，只改变作者与读者的距离；
- 是否存在把一个平台稿扩写或缩写成另一个平台稿的痕迹。

发现问题时修改发生问题的平台，不创建中间母稿统一四篇文章。

Markdown、标题、字数、段落长度和句式形状检查只能发现格式或候选风险，不能单独证明文章连贯、自然、有作者感。`05-验收报告.md` 不得用机械检查结果替代 `06-读者测试.md` 的阅读证据。
