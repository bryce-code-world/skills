# 读者连续性、心智迁移与冷读门禁

每次直接从内部底稿转写平台文章前读取。它只负责可解码语言、概念进入、内容主线和跨段连续性，不维护传播门禁问卷或通过状态。五道门禁唯一读取 [communication-effects.md](communication-effects.md)；开头、正文和结尾的独立设计分别读取 [opening-engineering.md](opening-engineering.md)、[body-engineering.md](body-engineering.md) 和 [ending-engineering.md](ending-engineering.md)。

## 建立可解码语言基线

写提纲、标题、封面和开头前，先从目标读者模型中区分：

```text
受众认知层级：
可用于识别主题的术语：
可直接参与理解的共同概念：
必须先解释的核心概念：
容易按日常含义误解的词：
必须保留的准确名称：
```

只检查决定本文理解的少数核心概念，不建立庞大术语账本。受众认知层级读取任务总结：普通大众只使用日常共同语言进入；主题半熟悉读者可以认出术语，却仍需先解释再推理；专业读者可以使用该群体真正共享的术语。读者“可能听过”足以让标题点名主题，却不足以让正文直接依赖其含义完成解释。

术语首次进入必须满足：

1. 先让读者遇到自己能识别的现象、问题或作用；
2. 即使暂时遮住术语名称，句子仍能表达这个概念是什么；
3. 再给出准确名称，并在后文稳定使用；
4. 日常含义与专业含义不同时，就近说清差异。

允许标题和封面点名目标读者能够识别、且正文准备解释的对象；即使读者不知道术语定义，也必须能看懂主题、相关性和阅读收益。新概念不得成为解释它自身的前提。以上约束覆盖任务总结中的传播主线、标题、封面文字、摘要、提纲、开头、小标题、正文和图片，不只检查完整正文。

## 参考已有写作方法

用户要求参考现成自媒体 Skill、样文或写作方法，或者当前工作区有直接相关的公开长文方法时，写提纲前读取最多三个最相关来源。只提取可迁移机制，例如具体场景怎样进入、问题怎样推进、观点和解释怎样交替、偏离后怎样扣回主线。

读取本地 Skill 源文件只是方法研究，不等于调用该 Skill。不得继承或复制作者身份、经历、人格、标志性口癖、粗口、固定标题、固定结尾、点击诱导和平台凭据。

## 为每个平台选择文章原型

根据底稿材料和平台阅读任务，分别选择真实经验复盘、认知变化、问题解释、观点论证、方法分享或能力演化中的一个主导原型。各平台可以不同，但必须表达同一底稿中的事实、观点、条件、主要目标效果和作者身份。

传播主线可以是读者共同经历、能力演化、核心问题、判断变化或持续场景，不强制使用作者当前工作作为案例。案例和具体锚点必须服务主题；它们让读者先理解案例本身时，应删除或降级为局部说明。

能力演化类文章按“已有能力 → 暴露问题 → 新能力为何产生 → 新能力又带来什么问题”推进。它可以完全依靠底稿事实和逻辑演化成立；没有真实案例时不得改写成虚构的个人认知变化。

不得把底稿章节、术语分类或检查清单直接翻译成正文目录。每个概念都要回答“目标平台的读者走到这里为什么正好需要它”。

## 建立段落推进链

写每篇平台稿前，内部回答：

```text
读者此刻已经知道什么：
这一部分点名了哪些解释对象：
这一部分可以直接使用哪些共同概念：
上一部分留下了什么问题：
这一部分只新增什么：
依靠底稿中的哪项材料：
怎样扣回标题和传播主线：
下一部分为什么自然出现：
```

任一部分无法填写时，合并、移动或删除，不靠“接下来我们看”制造假转场。连续两个部分无法扣回传播主线时，视为主线丢失。

专业概念按“读者熟悉的现象或困难 → 通俗作用 → 准确名称 → 回到主线”进入。不得在读者尚未遇到问题时成组倾倒术语，不得只用另一个陌生术语解释新概念，也不得用图片首次介绍正文没有解释的核心概念。

## 连接入口承诺与全文

写正文前确认：

```text
主要目标效果：
关键认知缺口：
入口承诺：
入口张力：
标题假设：
封面非语言任务：
开头怎样增加入口之外的新信息并交棒：
正文通过哪些内容回报持续兑现：
结尾要固化什么判断、方法、情绪或身份确认：
```

正文完成后反向检查。标题、封面或开头承诺了正文没有交付的收益时，降低承诺或补回底稿已有论证；底稿没有支撑时只能降低承诺，不能补造内容。

## 让第一人称承担证据

第一人称必须连接底稿或用户材料中真实存在的观察、动作、犹豫、取舍、判断变化或后果。只有“我后来发现”“我很认同”“我现在会”，但没有真实材料支撑时，只是语气外壳。

底稿没有真实经历时，直接清楚解释，不伪装成经验分享。不得为了“活人感”编造时间、地点、对话、情绪和结果。

## 向五道门禁提供连续性证据

五道门禁按 [communication-effects.md](communication-effects.md) 的唯一问卷执行。本文件只在同一次独立冷读中补充以下跨段证据：

1. 第一次无法直接理解的词或句子，以及读者当时的实际解释；
2. 遮住术语名称后，读者是否仍知道概念解决什么问题；
3. 第一次缺少上文前提或无法说明“为什么现在出现”的转场；
4. 连续两个部分不能扣回同一主线的位置；
5. 第一人称、案例和图片是否引入底稿或正文没有建立的内容；
6. 读完后能否不用术语清单口述核心关系和适用边界。

将这些证据与五道门禁回答、陌生场景迁移题、修改动作和复测结论一并写入 `06-读者测试.md`。发现概念无入口、主线中断、图片越权或身份空壳时，返回对应工程修正。没有独立读者时只能记录“设计自检完成，未独立验收”，不能把作者侧检查推断为通过。

## 执行跨平台复核

四个平台完成后，从内部底稿重新检查：

- 是否表达同一事实和观点强度；
- 是否因平台压缩产生相互矛盾；
- 是否有平台新增底稿不存在的案例、经历、数据或结论；
- 是否保持同一作者，只改变作者与读者的距离；
- 是否存在把一个平台稿扩写或缩写成另一个平台稿的痕迹。

发现问题时修改发生问题的平台，不创建中间母稿统一四篇文章。

Markdown、标题、字数、段落长度和句式形状检查只能发现格式或候选风险，不能单独证明文章连贯、自然、有作者感。`05-验收报告.md` 不得用机械检查结果替代 `06-读者测试.md` 的阅读证据。
