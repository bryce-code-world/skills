# 能力编排

`broadcast` 负责事实守护、大众基础长文、共享正文插图规格、公众号、知乎、CSDN 与掘金节奏重构和最终验收。公开长文默认调用 `$writing-style`；其他外部能力只在当前任务确实需要时调用。

准备调用外部 Skill 前，确认它出现在当前 Agent 的可用 Skill 列表中。缺失时按 [dependencies.md](dependencies.md) 处理，不根据本地目录推断可调用状态。

## 最小调用顺序

```text
原始材料
  ↓ 必要时
$lightning
  ↓
事实与观点账本 + 读者模型 + 传播主线
  ↓
$writing-style 写作前说明
  ↓
broadcast 完整大众基础长文
  ↓
$writing-style 基础长文去模板化编辑
  ↓ 返回缺失材料时
补入现有可靠材料 / 缩短基础长文 / 停止并请求材料
  ↓ 处理后重新执行去模板化编辑
  ↓
视觉必要性判断
  ↓ 结构与精确信息
$frontend-design → 可编辑源文件 → PNG
  ↓ 概念与编辑视觉
$canvas-design → 设计说明 → PNG
  ↓ 需要写实或复杂位图素材时
$imagegen
  ↓
共享正文插图生成、截图复核与嵌入
  ↓
基础图文门禁
  ↓
目标平台选择
  ↓ CSDN / 掘金时先执行
技术内容准入门禁
  ↓
按目标平台重构 Markdown
  ↓
$writing-style 平台稿语言终检
  ↓
平台标题契约机器检查
  ↓
平台封面和适配素材（同样按任务路由）
  ↓
四重验收
  ↓ 用户明确授权时
官方 Wechatsync
```

输入清楚时跳过 `$lightning`。没有个人风格档案时由 `$writing-style` 使用内置通用默认风格，不跳过去模板化门禁。没有投递授权时停止在本地发布包。

## 职责边界

| 能力 | 负责 | 不负责 |
|---|---|---|
| `$lightning` | 把零散或冲突材料整理为清晰内部稿 | 大众传播和平台写作 |
| `broadcast` | 基础长文、正文视觉决策、平台节奏、Markdown 和验收 | 长期风格档案、平台登录和发布实现 |
| `$writing-style` | 风格选择、去模板化编辑、身份保护和语言层验收 | 事实内核、传播主线和平台结构 |
| `$frontend-design` | 为精确结构和文字信息设计可编辑的 HTML/CSS 或 SVG，并指导反模板设计与截图复核 | 决定图片应该表达什么、生成互动网页 |
| `$canvas-design` | 为封面、概念视觉和编辑插画建立视觉哲学并完成静态画布 | 承载密集正文、改变文章观点 |
| `$imagegen` | 按既定视觉方向生成照片、写实场景、复杂插画或纹理素材 | 决定信息结构和艺术方向 |
| Wechatsync | 登录状态、素材上传和草稿投递 | 改写、事实判断和传播设计 |

## 调用 `$lightning`

提供原始材料、必须保留的事实和确认状态，并要求产出供 `broadcast` 使用的清晰内容内核。接收结论、来源、冲突、未知、条件、例外和风险。

不得要求它制造传播标题、案例和平台话术。

## 调用 `$writing-style`

写作前提供：

```text
内容内核：
主题：
目标读者：
内容目的：
风险：
目标平台：
用户指定风格：
用户空间：
```

接收主风格、场景语气、视角、读者关系、节奏、强化项、抑制项和不可改变项。

基础长文正文完成后提供全文、事实与观点账本、本次风格说明和不可改变项。请求执行完整去模板化编辑，并检查每个承担论证的段落依据什么材料，或者能否从前文事实直接推导，以及相比前文增加了什么。接收问题位置、最小修改、主动保留、缺失材料、内容内核检查、身份检查和待确认项。

收到缺失材料后由 `broadcast` 处理：

- 输入中已有可靠材料：补入基础长文；
- 没有材料支撑：删除或缩短对应段落；
- 缺口影响核心结论：停止生成并请求补充材料。

处理后重新执行基础长文去模板化编辑。未通过时不进入视觉和平台重构。

目标平台稿生成后提供各平台成稿及其内容形态。只请求检查平台改写重新引入的套话、机械节奏、风格漂移、身份冒充、虚构经历、场景失调、跨平台人格变化和语言导致的事实漂移。采用最小修正，不把不同平台改成同一种结构。终检后按 [platform-markdown-contract.md](platform-markdown-contract.md) 检查标题与正文分离，避免语言编辑重新加入 H1。

## 视觉路由

先由 `broadcast` 完成每张图的事实与信息规格：

```text
用途：
所在层：共享正文插图 / 公众号封面 / 知乎封面 / CSDN 封面 / 掘金封面 / 平台适配版本
正文位置：
目标画布与阅读宽度：
画面或信息层级：
准确文案：
来源项：
必须保留的限定：
替代文字：
禁止出现：
```

再根据信息任务路由，不根据输出扩展名或文章层级机械选择：

| 视觉任务 | 首选 Skill | 典型产物 |
|---|---|---|
| 对比、流程、因果、层级、连续谱、框架、数据、精确中文 | `$frontend-design` | `.html` 或 `.svg` + `.png` |
| 平台封面、概念视觉、编辑插画、视觉隐喻、气质表达 | `$canvas-design` | 设计说明 `.md` + `.png` |
| 照片、写实场景、复杂插画、纹理或位图素材 | `$imagegen` | `.png`，作为已确定视觉方向的素材或成品 |

封面需要精确框架或较多中文时使用 `$frontend-design`；正文需要纯概念视觉时使用 `$canvas-design`。一种图只调用完成它所需的最少能力，不为了“更丰富”叠加所有 Skill。

共享正文插图必须在基础长文门禁前生成并嵌入。平台封面、裁切和排版在平台 Markdown 完成后处理。

## 调用 `$frontend-design`

提供已经锁定的视觉规格，并要求它把任务视为固定画布的静态编辑视觉，不是完整网站或互动产品。

必须采用：

- 从主题、受众和图片唯一任务出发；
- 先定义颜色、中文字体角色、构图和一个标志性元素；
- 检查设计是否换一个主题仍然成立，成立时视为模板化并修改；
- 让编号、分区、线条和色块表达真实关系，不作无意义装饰；
- 生成可编辑的 HTML/CSS 或 SVG，再渲染为指定尺寸 PNG；
- 查看实际截图，完成至少一次视觉批评和精修。

不采用仅适用于交互页面的动效、悬停、键盘操作和页面导航要求。禁止默认套用米白加陶土色、近黑加荧光色、通用卡片栅格或与主题无关的报纸排版。

## 调用 `$canvas-design`

提供已经锁定的视觉规格和平台场景，要求先形成简短、主题专属的视觉哲学，再完成静态画布。

必须做到：

- 用空间、形式、颜色、比例、节奏和视觉隐喻表达主题；
- 文字稀少、准确、可读，不让生成式画面重写文字事实；
- 保留设计说明和最终 PNG；
- 按目标平台尺寸构图，并为裁切保留安全区；
- 查看实际图片，完成至少一次构图、字体、留白和边界精修。

`canvas-design` 不适合承载长段落、密集框架或必须逐字准确的复杂中文。遇到这些任务改用 `$frontend-design`。

## 调用 `$imagegen`

只有图片需要照片、写实场景、复杂插画或纹理素材时调用。由 `$frontend-design` 或 `$canvas-design` 已确定的信息结构和视觉方向约束生成结果。

图片中的关键中文、数据、流程和精确标签优先通过代码排版，不依赖生成模型直接写入。

生成后检查：

- 文案和图形关系是否准确；
- 是否添加来源不支持的数据、人物、场景和结论；
- 图片文字在目标阅读宽度下是否清楚；
- 视觉方向是否来自当前主题，而不是通用 AI 模板；
- 可编辑源文件或设计说明是否与 PNG 一起保留；
- 是否查看了实际渲染结果并完成至少一次修正；
- 视觉是否提高理解，而不是只增加装饰；
- 图片路径、图注和替代文字是否对应；
- 平台适配是否改变原图语义。

视觉工具不能反向修改内容事实。必要视觉不可用时保留准确规格，标记“基础长文已完成，图文产物未完成”。

## 调用 Wechatsync

只有基础门禁和四重验收通过，且用户明确授权时调用。

交付给下游：

- 准确的平台 ID 和账号环境；
- 目标平台 Markdown 文件；
- 已通过检查的 front matter 标题和无 H1 正文；
- 标题、摘要、正文、代码块、内容归属、分类、标签、封面和素材路径中的适用字段；
- 已授权动作；
- 已接受的人工处理项。

发布规则见 [publishing-wechatsync.md](publishing-wechatsync.md)。

## 失败隔离

- `$lightning` 缺失：按依赖规则降级；事实仍不清楚时停止转译；
- `$writing-style` 缺失：使用广播通用默认风格，按相同类别完成人工去模板化和内容内核检查，声明降级但不省略门禁；
- `$writing-style` 返回缺失材料：由 `broadcast` 补入现有可靠材料、缩短正文或停止并请求材料，不用语言扩写掩盖缺口；
- `$frontend-design` 不可用：精确结构图只交付视觉规格，不用艺术图替代，并把图文产物标记为未完成；
- `$canvas-design` 不可用：概念封面可在信息任务允许时降级为 `$frontend-design` 文字型封面，或在 `$imagegen` 可用时生成概念位图，并明确记录降级；
- `$imagegen` 不可用：继续完成代码生成信息图和文字型封面；只有确实需要位图素材的产物标记为未完成；
- Wechatsync 缺失或不可用：交付人工发布包；
- 单个平台失败：不影响基础长文和其他平台产物，不自动重复投递；
- 任一外部能力试图改变事实：拒绝修改并回到事实与观点账本。
