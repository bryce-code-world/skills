# 能力编排

`broadcast` 负责事实守护、大众基础长文、共享正文插图规格、公众号与知乎节奏重构和最终验收。只在当前任务确实需要时调用外部能力。

准备调用外部 Skill 前，确认它出现在当前 Agent 的可用 Skill 列表中。缺失时按 [dependencies.md](dependencies.md) 处理，不根据本地目录推断可调用状态。

## 最小调用顺序

```text
原始材料
  ↓ 必要时
$lightning
  ↓
事实与观点账本 + 读者模型 + 传播主线
  ↓
$writing-style 写作前说明（按需）
  ↓
broadcast 完整大众基础长文
  ↓
视觉必要性判断
  ↓ 必要时
共享正文插图生成与嵌入
  ↓
基础图文门禁
  ↓
公众号 / 知乎 Markdown 节奏重构
  ↓
平台封面和适配素材
  ↓
$writing-style 成稿后检查（按需）
  ↓
四重验收
  ↓ 用户明确授权时
官方 Wechatsync
```

输入清楚时跳过 `$lightning`。没有个人风格任务时使用广播通用默认风格。没有投递授权时停止在本地发布包。

## 职责边界

| 能力 | 负责 | 不负责 |
|---|---|---|
| `$lightning` | 把零散或冲突材料整理为清晰内部稿 | 大众传播和平台写作 |
| `broadcast` | 基础长文、正文视觉决策、平台节奏、Markdown 和验收 | 长期风格档案、平台登录和发布实现 |
| `$writing-style` | 风格选择、应用和语言层验收 | 事实内核、传播主线和平台结构 |
| 视觉能力 | 生成已经定义准确内容的共享插图和平台封面 | 决定事实、观点和文章结构 |
| Wechatsync | 登录状态、素材上传和草稿投递 | 改写、事实判断和传播设计 |

## 调用 `$lightning`

提供原始材料、必须保留的事实和确认状态，并要求产出供 `broadcast` 使用的清晰内容内核。接收结论、来源、冲突、未知、条件、例外和风险。

不得要求它制造传播标题、案例和平台话术。

## 调用 `$writing-style`

写作前提供：

```text
内容内核：
主题：
目标读者：
内容目的：
风险：
目标平台：
用户指定风格：
用户空间：
```

接收主风格、场景语气、视角、读者关系、节奏、强化项、抑制项和不可改变项。

成稿后只请求检查风格漂移、身份冒充、虚构经历、场景失调、跨平台人格变化和语言导致的事实漂移，并采用最小修正。

## 调用视觉能力

生成前完成每张图的规格：

```text
用途：
所在层：共享正文插图 / 公众号封面 / 知乎封面 / 平台适配版本
正文位置：
画面或信息层级：
准确文案：
来源项：
必须保留的限定：
替代文字：
禁止出现：
```

共享正文插图必须在基础长文门禁前生成并嵌入。平台封面、裁切和排版在平台 Markdown 完成后处理。

生成后检查：

- 文案和图形关系是否准确；
- 是否添加来源不支持的数据、人物、场景和结论；
- 图片文字在目标阅读宽度下是否清楚；
- 视觉是否提高理解，而不是只增加装饰；
- 图片路径、图注和替代文字是否对应；
- 平台适配是否改变原图语义。

视觉工具不能反向修改内容事实。必要视觉不可用时保留准确规格，标记“基础长文已完成，图文产物未完成”。

## 调用 Wechatsync

只有基础门禁和四重验收通过，且用户明确授权时调用。

交付给下游：

- 准确的平台 ID 和账号环境；
- 目标平台 Markdown 文件；
- 标题、摘要、正文、封面和素材路径；
- 已授权动作；
- 已接受的人工处理项。

发布规则见 [publishing-wechatsync.md](publishing-wechatsync.md)。

## 失败隔离

- `$lightning` 缺失：按依赖规则降级；事实仍不清楚时停止转译；
- `$writing-style` 缺失：使用广播通用默认风格并声明降级；
- 视觉能力不可用：交付视觉规格，文章可以完成，但图文产物不得标记为完整；
- Wechatsync 缺失或不可用：交付人工发布包；
- 单个平台失败：不影响基础长文和其他平台产物，不自动重复投递；
- 任一外部能力试图改变事实：拒绝修改并回到事实与观点账本。
