# 开头工程与第一屏门禁

当任务要求公开传播、争取陌生读者继续阅读，或优化文章开头时读取。开头负责把标题与封面获得的进入机会，转换成继续阅读的动力；它不是标题的扩写，也不是作者背景、宏观趋势或文章目录。

## 明确开头任务

写开头前确认：

```text
目标读者此刻认出了什么：
标题与封面已经承诺什么：
第一屏需要新增什么：
读者还缺哪个答案、判断或情绪出口：
正文准备沿哪条主线交付：
```

合格开头同时完成：

1. 让目标读者迅速确认“这与我有关”；
2. 承接标题与封面，但不换句话重复它们；
3. 在第一屏交付一个新增事实、观察、判断、场景或明确问题；
4. 建立一个读者能够理解、正文确实会补上的信息缺口；
5. 把阅读自然交给正文主线，不用“下面逐一介绍”代替推进。

只制造疑问而不给对象、相关性和最低信息，不构成有效信息缺口。普通读者必须先知道“我已经知道什么、还缺什么，以及为什么值得补上”。

## 用真实全文样本校准

传播机会是主要诉求时，标题与封面研究之后，再建立轻量全文样本包：

1. 优先采集同平台、同主题或相邻读者任务的 3 至 8 篇完整文章；
2. 至少包含 2 篇有公开阅读、互动、榜单或平台热门证据的高表现样本；
3. 分开记录文章表现证据与开头机制，不能因文章达到十万加就断言开头单独造成结果；
4. 只提炼可迁移功能，例如怎样建立处境、怎样交付首个信息增量、怎样留下正文会回答的问题；
5. 不复制作者身份、经历、固定句式和标志性语气。

无法取得完整正文时，不根据标题和摘要猜测开头结构。没有高表现证据时，把样本标记为普通编辑样本，不冒充爆文规律。

## 生成机制不同的候选

根据底稿已有材料，内部至少生成 3 个机制不同的开头方向：

- **共同处境**：从读者正在经历的困惑、成本或选择进入；
- **可观察现象**：先交付一个底稿已有的变化、结果、数据或对比；
- **核心矛盾**：让共同直觉与正文判断发生具体冲突；
- **直接判断**：先给出正文能够完整论证的关键结论，再解释原因；
- **微型场景**：用底稿已有的真实场景、动作或对象建立代入；
- **问题链**：只在多个问题共同指向同一根因时使用，通常不超过三个。

底稿没有真实人物、数据、事件或经历时，跳过对应机制。不同候选必须改变进入机制，不用同一句话替换近义词冒充比较。

## 执行开头淘汰门

逐个候选检查：

1. 第一段是否能够脱离内部讨论独立理解；
2. 是否比标题和摘要多交付了一项信息；
3. 陌生术语是否只用于点名解释对象，没有成为理解前提；
4. 是否只留下一个主要阅读缺口，而不是同时开启多条主线；
5. 正文第一部分是否正好接住开头留下的问题；
6. 删除开头后，读者是否会失去继续阅读的具体理由。

宏大背景、作者履历、标题复述、术语清单、连续空问句、虚构经历、预告式目录和无法由正文兑现的悬念，直接淘汰。

## 执行第一屏门禁

只提供最终标题、最终封面和正文第一屏，不提供底稿、提纲、任务总结和预期答案。让测试读者回答：

1. 这篇文章此刻在处理什么具体问题；
2. 开头比标题和封面多告诉了我什么；
3. 我现在最想继续知道什么；
4. 哪一句造成了继续阅读或退出；
5. 第一段结束后，下一部分应该自然回答什么。

读者只能复述标题、说“主题很清楚”，或者不知道正文接下来为什么出现，第一屏门禁失败。修改开头后复测；标题与开头建立了两种不同承诺时，联动降低或重做入口。

## 研究依据与边界

- [The Psychology of Curiosity](https://doi.org/10.1037/0033-2909.116.1.75) 将好奇解释为对知识或理解缺口的感知。它支持“让读者看见可补足的缺口”，不支持故意隐瞒主题或制造虚假危机。
- [When curiosity gaps backfire](https://pmc.ncbi.nlm.nih.gov/articles/PMC11704130/) 提醒具体性与点击并非简单线性关系。开头需要在足够清楚和仍有问题之间校准。
- [AI 奶奶文章](https://www.newrank.cn/article/detail/28132) 从新现象、可观察数据和三个同根问题进入；[延迟退休文章](https://www.bohaishibei.com/post/92978/) 从读者共同处境和荒诞想象进入。两者说明高表现文章可以使用不同机制，不能提炼成统一句式。

研究和样本用于提出开头假设，不用于承诺完读率。真实第一屏退出和继续阅读只能在授权发布并取得平台数据后评估。
