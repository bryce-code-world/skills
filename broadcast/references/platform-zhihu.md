## 输入契约

开始前确认：

- `01-大众基础长文.md` 已经通过基础门禁；
- 事实与观点账本、主风格和不可改变项可用；
- 共享正文插图已经生成，或明确记录为无需；
- 目标是知乎独立文章。

缺少完整基础长文时返回共同上游，不在本文件补写核心内容。

## 重构目标

知乎文章面向独立议题、机制解释和长期检索。重构重点是让命题清楚、推理可跟随、争议和边界可见，同时保持普通读者能够进入。

可以调整：

- 将标题改为清楚、可检索的问题、判断或阅读收益；
- 开头直接提出命题及其现实意义；
- 提高概念、推理和证据的显性程度；
- 将已有反例、限制和误解移动到对应论断附近；
- 展开基础长文已有但过于简略的解释；
- 压缩只服务公众号关系语境的铺垫和转场；
- 结尾交付可复用的框架或判断。

不得新增基础长文中不存在的事实、案例、经历、核心观点和第二主线。需要实质补充时先修改基础长文并重新验收。

## 阅读节奏

优先采用：

1. 标题形成一个可以独立成立的命题。
2. 开头较快给出核心判断和为什么值得理解。
3. 首次出现专业概念时给出通俗入口和准确含义。
4. 正文按概念、判断、证据、推理和应用推进。
5. 主动处理最可能的反驳、限制、误解和适用边界。
6. 数据、来源名称和作者判断贴近对应论断，不在文末集中列参考资料。
7. 结尾提供读者能够复用的判断框架，不强制点赞、关注或互动。

知乎允许较高信息密度，但不能用术语堆叠代替解释，也不能用权威口吻代替来源和推理。

## Markdown 产物

输出 `03-知乎文章.md`，使用带结构的 Markdown。默认使用机器可读的元数据区，并保持正文独立可读；当前环境已有等价明确协议时可以映射为该协议：

```markdown
---
platform: zhihu
title: "推荐标题"
summary: "文章摘要"
cover: "assets/zhihu/cover.png"
source: "01-大众基础长文.md"
---

# 推荐标题

正文……

![准确的替代文字](assets/shared/example.png)

图注……
```

如果当前发布入口使用其他元数据协议，在投递阶段映射字段，不把发布参数写进正文。下游必须把元数据区解析为字段，不能渲染进文章；平台标题字段已经使用标题时，正文渲染应避免重复显示首个 H1。Markdown 是内容真相源，知乎编辑器中的呈现是下游渲染结果。

正文格式可以使用：

- 标题层级；
- 自然段；
- 列表；
- 少量强调；
- 链接、图片和图注。

## 公开正文硬限制

知乎成稿不得出现：

- 三个反引号或三个波浪线形成的围栏代码块，包括用来排版普通文字的 `text` 代码块；
- 以 `>` 开头的 Markdown 引用块；
- Markdown 表格、ASCII 图、空格对齐的多列文本和 `<pre>` 等不自动换行结构；
- 作为独立可见文本的长网址、长路径、长命令和连续标识符；
- “参考资料”“参考文献”“资料来源”“来源列表”等文末章节；
- 脚注、尾注和编号链接列表。

对照内容改为分点列表或常见阅读宽度下可读的纵向信息图。需要保留原话或重点结论时写成自然段，必要时使用少量加粗。必须说明出处时，在相关句子中自然写明来源名称，并把链接附在简短名称上。完整来源、素材授权和风险信息只写入 `06-验收报告.md`。

## 视觉处理

- 复用基础长文中的共享正文插图；
- 按 [orchestration.md](orchestration.md) 的视觉路由生成知乎封面和必要的裁切版本：概念型、编辑型封面优先 `$canvas-design`，精确框架或文字型封面优先 `$frontend-design`；
- 根据论证顺序调整插图位置，不改变图片语义；
- 保证图片文字在常见阅读宽度下清楚；
- 保留封面的设计说明或可编辑源文件，以及最终 PNG；
- 实际查看渲染结果并完成至少一次视觉批评和修正；
- 不用封面或图注把有限结论扩大为普遍定律。

## 交付与验收

交付：

```text
03-知乎文章.md
assets/zhihu/
```

检查：

- 标题是否形成准确、独立且可检索的命题；
- 开头是否快速给出判断和阅读价值；
- 结论是否有推理、来源或明确的作者判断支撑；
- 事实、推断和观点是否清楚区分；
- 边界、反例和可能争议是否得到处理；
- 是否保留基础长文的事实、主线和观点强度；
- 是否完全不存在围栏代码块、引用块、Markdown 表格、ASCII 排版和横向滚动结构；
- 是否没有参考资料、参考文献、资料来源、脚注、尾注和编号链接列表；
- 是否与其他已生成平台版本形成真实语境差异；
- 共享插图、封面和适配素材是否完整；
- 是否没有新增基础长文之外的实质内容。
