# AI 视频制作

让当前 Agent 完成内容判断和创作，工具执行重复的制作与检查。**普通用户打开作品目录就能看到成品 MP4、中文分镜和分类媒体素材**，机器源码、JSON 与依赖统一收在专业工程目录。输出规则见 [中文作品目录](docs/PROJECT_LAYOUT.md)。工具运行成功只证明技术执行完成。

## 创作与交付

1. **确定表达目的。** 从用户材料提取观众、问题、核心价值和证据。宣传片重点是痛点、改变与可见结果；操作教程重点是步骤。用户未要求教学时，不把安装过程和按钮说明作为宣传主线。约束明确就继续，缺少会改变主题的事实才提问。
2. **先验证代表片段。** 先找至少一项真实、获准使用的输入及实际成果变化；没有证据则明确示意，不以终端日志、波形、文件树或进度条充当展示效果。先完成开场与关键镜头，检查手机可读性，再展开全片。**一段自然配音可以跨多个镜头**；独立同步字幕以真实配音时间为准，`caption` 只是画面提示。
3. **按任务制作。** 单条视频无需额外文本模型 API、七个平台账号或完整品牌知识库。内置模板负责起步，复杂镜头直接修改工程；已安装的 video-shotcraft 可按需参考少数镜头配方。不要为简单任务安装整套第三方工作流。
4. **检查并交付。** 先核对实际尺寸、时长、音轨、字幕和版本哈希；镜间低声能空档若超过 0.8 秒需关注，超过 1.2 秒优先排查叠加静音。抽看关键镜头与同步字幕，正常速度核对音画和发音。记录具体时间点、结果和未验证项。缺少试听能力时说明限制，不用 ASR、波形或脚本正确冒充听感验收。交付 MP4、工程路径及必要说明，不能只给分镜或预览服务器。

## 共同边界

- 先按 [工作区规则](AGENTS.md) 复用已登记环境；新作品保存在 `workspace.json.output_root/<内容ID>`，使用 [中文目录规范](docs/PROJECT_LAYOUT.md)。用户直接编辑中文分镜、通过 `studio rebuild` 重渲；已有历史项目不迁移、不覆盖。
- 快速渲染记录为 `technical_only`，不自动生成审核 PASS。需要完整审核和发布包时进入完整生产分支；两种模式都应实际检查画面和声音。
- 制作不代表公开发布授权。发布平台、账号和版本检查以 [内容契约](docs/CONTENT_SCHEMA.md) 为准，不擅自付费、登录、投稿或覆盖其他项目。
- 原有工具、脚本和工程能完成任务就直接复用。选择外部能力时参考 [工具边界](docs/TOOLCHAIN.md)，不把可选工具变成所有任务的前置条件。
