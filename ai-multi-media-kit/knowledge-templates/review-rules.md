# 内容审核标准（企业可直接编辑）

审核五个维度，默认各 20 分，合计 100 分：
1. 事实准确与可追溯（20）：涉及数据、引用、客观结论应给出原始来源；缺乏依据不得当作事实发布。
2. 品牌一致性（20）：符合品牌定位、人设、价值观及禁用表达要求。
3. 用户价值与表达（20）：前 3～5 秒体现具体观众问题/看点；以真实使用场景、前后对比或可验证的示例证明一个核心价值，不把功能罗列和技术口号当作吸引人的脚本；口播简短自然。
4. 平台规范及合规（20）：尊重版权、广告标识、隐私、行业禁令和各平台要求。
5. 视频可执行性（20）：分镜时间之和与总时长一致，按真实 TTS 测速配时；使用合法镜头或明确标注的原创示意，避免全程 PPT 式方框/流程图；字幕跟随真实音频时序，成片实际试听与抽帧检查自然度、空镜头、异常静音、节奏。

建议阈值：`>= 85` 为 PASS 候选；`70-84` 为 REVISE；`< 70` 为 BLOCK。
硬性阻断：明显虚假事实、未经授权的私人信息、无权使用的影视/音乐/图片素材、含风险的违法或违规宣传；**解码后配音异常加速、长时间静音、字幕与实际语音明显错位、无法真实试听/查看却宣称音画验收通过**，均不允许作为可发布成片 PASS。

> 以上是初始质量基线，可按品牌/平台细化。`studio check` 的音频技术检查无法判断语音自然度、语义是否正确或镜头是否有吸引力；这部分需要 Agent 确实试听/查看成片并记录证据。既有用户知识库不因 Skill 升级而覆盖。
