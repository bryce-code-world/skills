# 中文作品目录

每条视频都是用户能直接浏览和修改的作品，不应要求普通人了解工程文件。

```text
<内容ID>/
├── 成品视频.mp4                  # 当前成片，完成制作后出现
├── 视频封面.png                  # 从当前视频自动抽帧生成
├── 打开这里.md
├── 01-文案与分镜/
│   ├── 视频文案.md               # 指向唯一口播来源，不重复保存两份
│   ├── 分镜脚本.md               # 画面、口播、时长、素材与精确时间位置
│   └── 字幕文件.srt              # 使用外部字幕时才出现
├── 02-媒体素材/
│   ├── 图片/
│   ├── 视频片段/
│   ├── 配音/                     # 分段原始音与合成旁白分别保留
│   ├── 背景音乐/
│   └── 音效/
├── 03-修改与版本/
│   ├── 修改记录.md
│   └── 旧成片-<时间>.mp4          # 有过重渲染才出现
└── 99-专业工程/
    ├── content.json / script.json / shotlist.json
    ├── user-storyboard.json
    ├── video/render.json / review.json
    ├── work/ / history/         # 计划、审核、技术备份
    ├── work/samples/<样片ID>/   # 本次任务采用的内部独立样片工程（仅需要时）
    ├── src/                     # Remotion 源码
    └── package.json / node_modules / ...（适用时）
```

**单一素材来源**：Remotion 的 publicDir 指向 `02-媒体素材`，没有重复的 `public`；FFmpeg 只把实际使用的素材归档到这些用户目录，不再做一套供展示的拷贝。逐段配音与合成旁白是不同用途文件，均可供用户查找。

**编辑源**：`01-文案与分镜/分镜脚本.md` 的时长、画面、口播、图片/视频及配音是普通用户的编辑入口。新版增加通俗的 `视觉风格`、`表现方式`（如成果展示、特写、三步拆解）及用到时的 `三步内容/对比前后图`，Agent 可以直接据此修改底层导演镜头，历史分镜无需迁移。分镜顶部可更换 `连续旁白`；`字幕文件.srt` 是独立的真实语音字幕时间轴。自动计算的开始/结束时间及帧号只用于定位，修改时长后重新计算，不存在第二条人工维护的时间轴。`99-专业工程/shotlist.json` 是由中文分镜同步后的机器执行表示。

**项目归属**：一次制作请求只有一个对用户展示的顶层作品；测试镜头应在该工程中完成，独立样片先写入工具临时目录，再用 `studio nest-sample` 归入正式项目的 `99-专业工程/work/samples`。归档保留样片及编辑工程，不移动其他任务历史作品。项目根目录继续使用带 Agent/轮次的 content_id，不能用中文标题代替身份；标题与内容是中文文档。历史项目和旧 `studio new --id` 的 schema 3 保持原结构，绝不自动迁移、复制或覆盖。

## 如何修改并重新制作

1. 修改 `分镜脚本.md` 里对应镜头的时长、内容、素材路径。图片和配音必须引用项目内 `02-媒体素材` 的合法文件。
2. **修改口播必须重新生成受影响的配音**并更改顶部 `连续旁白` 或分镜的配音路径；只改画面、镜头长度可复用未变音频。字幕独立于镜头：编辑 `字幕文件.srt` 后重渲染会重新同步 cue，检查文字和实际时长，时间调整不能冒充经过真人试听。
3. Agent 可以用 `studio storyboard --id <ID> --apply` 同步中文分镜并备份旧工程，或运行 `studio rebuild --id <ID>` 一步同步并重新渲染；后者仅适用于新式 Remotion 作品。先用 `--dry-run` 只读校验。
4. 所有技术渲染检查成功后，新的 `成品视频.mp4` 才替换根目录成片；旧 MP4 和旧封面保存在 `03-修改与版本`。工程 JSON 备份保存在 `99-专业工程/history`，不暴露在用户普通目录。
5. 当前渲染哈希同步更新；**旧审核结论失效**。实际画面、字幕、听感仍需新一轮检查，快速模式不自动获准发布。

```powershell
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio rebuild --id "<内容ID>" --dry-run
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio rebuild --id "<内容ID>"
```

首次写完机器脚本后，Agent 可用 `studio storyboard --id <ID> --from-engine` 生成中文分镜。已有人工修改时不能反向覆盖，应先 `--apply`。高级动画仍修改 `99-专业工程/src`。

## 与完整生产模式的统一规则

正常 `studio new --topic ... --agent ...` 新建中文作品项目；其工作文件放在 `99-专业工程`，所有素材和成片从人类可见路径访问。脚本、审核、配音、FFmpeg 渲染、平台包和发布记录都通过同一个内部工程根读取，不需要各自另建项目。

- 新项目：`<项目>/99-专业工程/content.json`，最终视频 `<项目>/成品视频.mp4`。
- 历史项目：`<项目>/content.json`，最终视频 `<项目>/video/master.mp4`。
- 素材：新项目使用 `02-媒体素材/`；旧项目保持原路径。
- 项目目录 ID、用户已授权素材来源与用户修改不得因更新目录结构而丢失。
- 不是每个视频都会用到音乐、字幕、图片或音效，没有生成的文件不应伪装成已存在。
