# 单条视频制作与定点修改

**用户只需提供选题、背景资料、目标观众和希望达到的效果。** Agent 负责分镜、合法素材、配音、画面、字幕与质量检查；不要让用户填 JSON 或了解 Remotion 源码。简单制作不要求七个平台账号、额外文本模型 API 或完整知识库审核。

交付格式统一见 [中文作品目录](PROJECT_LAYOUT.md)。核心是根目录的 `成品视频.mp4`、可直接读写的 `01-文案与分镜`、`02-媒体素材`，和普通用户无需进入的 `99-专业工程`。

## 制作原则

1. 从用户真实问题入手，先确认受众、核心价值和具体展示证据。产品宣传突出改变，不要默认拍安装操作或科技流程图。
2. 优先使用真实且已授权的素材，不够时用明确的原创示意。先验证一个代表镜头和自然中文旁白，确认可读性后展开全片。
3. **口播按完整语义句生成。** 镜头切换、字幕显示折行都不能切断一个词。字幕以真实音频配时；没有词级对齐只能声称句级同步。不要机械叠加多段静音、强行加速或截断语尾。
4. 正式交付前检查最终 MP4 的尺寸/时长/音轨、每镜头字幕及安全区、发音、停顿与相邻镜头。不能实际听音时说明未验收，不能用 ASR 或波形代替。

## 直接制作

Agent 根据任务生成一份最小 JSON 分镜，普通用户不用查看。例如：

```json
{
  "title": "解决重复整理的问题",
  "audience": "需要处理大量素材的人",
  "primary_value": "减少手工搬运",
  "aspect": "9:16",
  "shots": [{
    "title": "每天都在反复整理？",
    "caption": "文件和音频散落",
    "seconds": 5,
    "image": "素材示意.png",
    "voiceover": "素材一多，整理和剪辑总要来回搬。",
    "audio": "自然配音.wav"
  }]
}
```

`image` 和 `audio` 可省略，但缺少音频时只交付无旁白技术预览，不得宣称已具备自然口播。每镜头 2～20 秒，1～12 镜头，总时长不超过 180 秒，30fps。PNG/JPG/WebP/SVG 图片、PCM WAV/MP3/M4A 配音，单文件上限 80MB，压缩音频须用 ffprobe 测真实时长；每段语音要有至少 0.15 秒尾余量。

```powershell
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio quick --spec "<由 Agent 编写的分镜.json>" --topic demo --agent codex --dry-run
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio quick --spec "<由 Agent 编写的分镜.json>" --topic demo --agent codex
```

- 默认 9:16 / 1080×1920，支持 16:9 / 1920×1080。
- 复用当前工作区的 Node/npm，第一次项目按固定 lockfile 安装本项目依赖；不改变系统 PATH。网络、费用和浏览器资源依当前可用性独立核验。
- 默认使用套件自己的 Remotion 模板。`--shotcraft-dir` 可显式选用已安装 video-shotcraft 的依赖模板，**不自动迁移外部动画或音乐**。
- 成品位置：`<项目>/成品视频.mp4`，同时自动生成 `视频封面.png`；素材一次性归到中文 `02-媒体素材`，Remotion 源码、依赖和机器时间轴位于 `99-专业工程`。

## 定点修改

用户只需说“把 23～26 秒的图片换掉，配音保持不变”。Agent 打开当前 `01-文案与分镜/分镜脚本.md`，参照自动显示的秒数/帧号找到镜头，修改画面、时长和素材引用；高级动画可改 `99-专业工程/src/`。

**最短可控闭环：**

```powershell
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio rebuild --id "<内容ID>" --dry-run
& "<工具目录>\RUN-STUDIO-WINDOWS.ps1" -Task studio rebuild --id "<内容ID>"
```

此命令仅适用于新版 Remotion 工程：预先校验中文分镜及音频时长，自动同步专业工程，重新渲染并验证，成功后替换根目录 MP4；原成片与旧封面保存于 `03-修改与版本`，旧技术数据备份在 `99-专业工程/history`，旧视频审核失效。

需要只同步机器数据时用 `studio storyboard --id <ID> --apply`；Agent 首次把已有机器脚本生成为中文分镜则用 `--from-engine`。用户已修改分镜时不得从引擎覆盖其内容。

- 只改画面：复用配音。
- 改口播：重新生成受影响音频，将新文件放到 `02-媒体素材/配音` 并更新分镜中的路径；只改文字不换配音会被拒绝。
- 改时长：脚本的 seconds 和机器 frames 统一同步；不得削掉尾音。
- 改字幕：以新音轨的时间轴为准；如需 SRT，文件保存在 `01-文案与分镜/字幕文件.srt`，不要把它当成声音分段的依据。
- 只改 Remotion 动画：不重新生成音频、不另起项目，复用现有依赖。
- 用户不应直接覆盖根目录 MP4 来冒充完成审核；重新渲染会更新当前渲染哈希，仍需做视觉与听感检查。

Remotion Studio 在 `99-专业工程` 目录执行 `npm run dev`。手工渲染区间/静帧供高级编辑使用，不代表最终用户成片已经更新。其他引擎沿用自身命令和编辑数据，不强制转换 Remotion。

需要企业审核、素材库批量搜索、平台打包或公开发布时，才进入 [完整生产](../.agents/skills/ai-media-studio/SKILL.md) 和 [内容契约](CONTENT_SCHEMA.md)。快速制作生成的 `technical_only` 状态绝不自动升级为“已审核通过”。
