| A01 | Windows 初次无 Python、uv | 用户目录下自带 Python 3.12/uv，工具落在指定目录 |

| A07 | FFmpeg 与 ffprobe | 工具可以真正启动并检查音视频 |
| A08 | 断网且依赖缺失 | 不装未知/付费工具，明确阻塞 |
| A09 | `doctor --scope core --strict` | 本地运行时/子 Skill/知识库结构通过 |
| A10 | 脚本经 AI 审核 PASS | 可直接渲染，无 `studio approve` / 用户口令 |
| A11 | 脚本修改、审核标准改变、未核事实 | 强制重新 AI 审核或 BLOCK，不伪造 PASS |
| A12 | 真实成片 | 可播放 MP4，音视频/尺寸/时长经验证 |
| A13 | 视频 AI 审核 | `video/review.json` 全 PASS、无问题，绑定视频/脚本/标准哈希才可打包 |
| A14 | 视频变更/旧审核 | 旧质量验收失效，不需要真人验片 |
| A15 | 七平台内容包 | 成片/脚本质量有效时生成，打包不发布 |
| A16 | 只制作、未在初始任务指定发布目标 | `publish --execute` 必须拒绝 |
| A17 | 初始任务授权 `douyin:main` | 只允许该账号发布，其他平台/账号拒绝，无 `PUBLISH` 二次确认 |
| A18 | 超时、重复提交与未知状态 | 不能重复盲发；需核实对应平台的真实 HTTPS 作品链接后才能标为成功 |
| A19 | 安装/重复运行/用户资产 | 素材、审核数据不丢失，路径可恢复 |
| A20 | 多来源素材登记 | 保留原片、不覆盖索引授权、可提取真实帧 |
| A21 | 未核实授权、素材变化或缺失 | 拒绝使用；Agent 自行切换合法方案 |
| A22 | 免费网络素材 | 只在许可/费用已核实时尝试 `--execute`，不弹出 `FETCH` 口令 |
| A23 | 新会话共享路径索引 | 同 OS 用户可复用；损坏停止，不猜测工作区 |
| A24 | 不同 Agent 运行 | 同一用户/机器上能识别 Skill/复用环境；不假定特定客户端有本地命令 |
| A25 | 账号扫码/验证码 | 确需本人操作时暂停，完成后续跑；其他正常质量流程不询问审批 |
| A26 | 收费或未经授权的公开行为 | 默认禁止，不能借“无中间审批”绕过 |
| A27 | 自动 AI 返工上限 | 默认最多三轮，无法解决时报告原因与真实完成范围 |
| A28 | 独立项目成果根目录 | 首次 `--output-root` / `-OutputRoot` 指定与工具/知识库不嵌套目录，所有脚本、视频、平台包按 ID 写入该处；工具目录不再生成重复成果 |
| A29 | 跨 Agent / 重复初始化 / 旧版兼容 | 新 Agent 从共享工作区的 `config/workspace.json` 取得 `output_root`；未指定保留旧位置；再次安装不迁移、不覆盖已有项目 |
| A30 | 输出目录合法性与资产导出 | 非法相对路径/嵌套目录或直接改变已有路径要拒绝；离线测试和 ZIP 导出读取成果真实位置，ZIP 不能写入被导出根目录 |
| A31 | 新 Agent 发现有效环境 | 共享索引与工作区三目录只读核验通过，不再询问路径、运行初始化或重复下载安装；第二次调用不修改已有资产或配置 |
| A32 | 防止第二套默认环境 | 新 Agent 指定另一工具路径默认被拒绝，已有索引无效或三路径冲突也拒绝新建；仅用户显式 `--new-workspace` 才可创建第二套 |
| A33 | 缺失索引恢复 | 已知真实旧工具路径时 `inspect` 只读验证，`register` 可重新登记；不需要重新初始化工作区或下载安装依赖 |
