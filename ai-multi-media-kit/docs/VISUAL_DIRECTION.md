# 视觉导演：让画面承担叙事

**定位：** Agent 自主理解用户问题、受众、素材和想传达的变化，再为每镜头选择视觉表现。用户只需给选题和资料，**无需学习这些字段**。继续使用原连续配音、字幕时间轴、Remotion、中文作品目录，不新增 TTS/ASR 或第三方运行时。

## 依据“观众应看见什么”选镜头

| 口播意图 | 视觉表现 | 前置证据 |
| --- | --- | --- |
| 冲突、问题 | `kinetic` 动态重点字；有素材时 `focus` 缓慢推进 | 真实问题描述 |
| 真实产品、界面和效果 | `showcase` 大画幅展示 / `focus` 聚焦素材 | 经授权的图或视频 |
| 真实前后变化 | `compare` 对比镜头 | **两张内容不同的真实前/后图**，不自动生成对比事实 |
| 讲具体操作过程 | `steps` 三步镜头 | **三条真正来自案例的步骤**，不填占位词 |
| 最后成果 | `reveal` 结果出现与放大 | 独立成果素材，而非把宣传片剪回宣传片 |
| 强调观点 | `kinetic` 动态重点文字 | 简短并可解释的主张 |
| 旧工程或手动要求 | `standard` 原标题＋素材布局 | 沿用已存在的画面 |

当 Agent 没有指定 visual_mode 时，程序根据口播与素材做**保守选择**；不能只看到“对比”两个字就捏造前后图。Agent 可以明确指定 visual_intent 和 visual_mode，但不需要普通用户配参数。

**产品主体优先于镜头效果**：花字和运镜不能代替品牌定位。命名产品介绍的第 2 个镜头（或更早）必须完整显示产品名、旁白必须自然点名；最终镜头回到同一名称。不要把 `ai-multi-media-kit` 的介绍拍成“任何一个 AI 都能这样做”。先锁定名称、独特用途和能证实的效果，再决定动效。

## 三套视觉语言

- `product` / 简洁产品风：蓝青主色，适合 UI、产品、数据对比
- `warm` / 温暖知识风：暖色、平易近人，适合知识讲解、步骤
- `social` / 快节奏社媒风：更醒目的强调色与重点字，适合手机短视频

整片原则上统一一种风格，但**镜头构图要有变化**。换风格是为了服务主题，而不是把滤镜当作专业感。仅在品牌规则允许时切换主色。

## Agent 输入片段（不要求用户写 JSON）

```json
{
  "visual_style": "social",
  "shots": [
    {"title":"为什么一直在来回整理素材？","seconds":4,
     "visual_intent":"problem","visual_mode":"focus","image":"经授权的画面.png"},
    {"title":"调整前后","seconds":5,"visual_mode":"compare",
     "before_image":"之前.png","after_image":"之后.png"},
    {"title":"一次整理三步走","seconds":5,"visual_mode":"steps",
     "steps":["收集","分类","复习"]}
  ]
}
```

这是镜头字段片段，不是完整制作 JSON。图片仅为格式示例。实际视频仍需要脚本、身份、配音、字幕时间、素材来源等原有字段。

## 最短质量闭环

1. **口播先行**：先写自然语义段并用一条连续语音合成；镜头运动不改变配音断句。
2. **代表镜头先行**：优先做开场问题、一个真实过程和一个最终成果，真实查看手机竖屏画面，不默认套用六页标题卡。
3. **真实效果优先**：尽早展示独立成果；代码目录、终端日志、审核得分默认留在技术说明，而不放入主体画面。
4. **保留编辑**：中文分镜支持修改镜头表现、全片风格和原素材，`studio rebuild` 重渲染并归档旧成片，未变化的配音与字幕复用。
5. **对照试验**：同一文案、配音、画面素材分别制作原始版与增强版；检查视觉变化、字幕安全区、镜间停顿、编辑恢复和返工成本。只有真正改善的镜头才保留。

**技术可运行不等于观众愿意看完。** 模板必须有真实成片抽帧检查；实际中文语气和读音必须试听，不能拿 TTS 文本或静音检测伪造 PASS。

## 借鉴而不引入负担

现有 `assets/quick-remotion/Director.tsx` 是本套件独立实现的轻量镜头组件，无外部媒体或第三方动效运行时代码。参考这些公开方法，不将它们安装成必选依赖：

- [Remotion 官方 Skills](https://github.com/remotion-dev/skills)：时间轴、相机运动、字幕、字体排版、真实帧复查
- [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)：真实素材与镜头配方，代码文档 Apache-2.0；其音效和音乐许可需单独核查
- [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)：多种视觉风格和镜头表现的学习参考，具体资源使用前另查当前许可证
- 非商业许可证的相关镜头项目只借鉴通用方法，不复制到可能商业化的 Skill

长期只沉淀“镜头意图 → 经验证的配方 → 实际失败与修正”这些有复用价值的经验，不无限扩建组件和审批流程。
