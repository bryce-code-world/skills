# 工作区规则

制作入口是 [SKILL.md](SKILL.md)。本文件只定义共享环境、项目归属和权限边界；内容结构、发音与发布检查统一见 [内容契约](docs/CONTENT_SCHEMA.md)，不在此重复流程。

- **复用环境**：先只读检查共享安装索引和 `config/workspace.json`。有效环境直接复用；索引缺失时用已知工具路径检查并恢复。索引损坏或路径冲突时报告，不据此新建第二套环境。发现、首次安装和升级命令见 [START_HERE](docs/START_HERE.md)。
- **目录归属**：正式成果只写入 `workspace.json.output_root/<内容ID>/`。新作品采用 [中文作品目录](docs/PROJECT_LAYOUT.md)：根目录 MP4、中文分镜、分类媒体与 `99-专业工程`；不额外复制一套媒体。旧项目保留原路径。新任务使用 `--topic/--agent`，模型名只填可核实值。不同 Agent 的独立方案用独立 ID；接力新方案用 `--parent-id`。指定既有工程可定点修改，保留旧成片与版本且不并发写入同一 ID。
- **按需依赖**：复用已安装的 Python、Node、FFmpeg 与项目锁文件，不改系统 PATH。只补齐当前任务实际需要、来源和费用已核实且已有授权的依赖；未知费用、越权或无许可素材不能自动放行。
- **能力与证据**：核对宿主实际文件、终端、图像和音频能力。只读文档不等于运行工具；退出码、音轨存在和文本一致都不等于视觉/听感合格。记录真实结果，不生成虚假 PASS。
- **任务授权**：用户已授权的制作过程连续完成，不要求逐阶段审稿。发布、收费、外传和账号操作仍受当前任务授权限制；身份验证确需本人时再暂停。
- **保护与恢复**：不覆盖别的 Agent 或用户的资料。内容修改使旧审核失效；不改旧记录来扩大发布范围。升级使用新源码的升级脚本，备份将替换的自有文件，保留知识库、配置、账号、运行时和历史作品。升级会替换套件自有文件，先检查其中的用户定制。
- **执行入口**：使用已有工作区启动器的绝对路径。Codex 专用启动器/MCP 配置不是其他宿主的前提；源码、客户端已安装 Skill 和工具工作区分别核对版本。
