# 选题 Skill

1. 从配置定位企业知识库，读取品牌、受众、方法、成功案例及配置中 `output_root` 下的历史成果，避免重复题材。
2. 按用户问题、真实证据、素材可得性和成本筛选；优先高价值、可核实、合法免费制作的主题。热点事实需要核对；未经核实的案例只能作为待查候选，不能当成真实素材。
3. 每条选题保留目标受众、视角、开头钩子、时长、事实来源、素材需求、适配平台和风险。批量选题写入 `<output_root>/_plans/<YYYYMMDD>-<agent>-<run>-topics.*`，其中 `output_root` 从工具工作区 `config/workspace.json` 读取；不覆盖历史。
4. 初始任务已要求制作时，由 AI 自主选择最合适选题进入脚本阶段，不另外请用户人工确认。目标不清且影响基本方向时才询问必要信息。

同一主题可由多个 Agent 分别创作，但应共享 topic_id、使用不同内容 ID。策划阶段先区分核心用户价值、次级优势与工程测试事项，不把工具复用/安装说明自动当成宣传重点。
