# 与广播的集成

## 职责

| 能力 | `writing-style` | `broadcast` |
|---|---|---|
| 收集和提炼风格 | 负责 | 不负责 |
| 管理档案和默认风格 | 负责 | 读取结果 |
| 场景语气 | 负责 | 提供话题、读者和风险 |
| 关系与声音实现 | 负责语言层构造与身份保护 | 负责推导传播关系契约 |
| 事实、观点和传播主线 | 不改变 | 负责 |
| 平台结构和形态 | 不决定 | 负责 |
| 语言层应用 | 负责 | 接收调整 |
| 去模板化编辑 | 负责问题识别、最小语言修改和身份保护 | 提供内容内核并执行门禁 |
| 最终验收 | 风格与身份 | 事实、传播和平台 |


`writing-style` 返回：


没有个人默认档案时使用内置通用默认风格。

指定档案不存在时，不虚构档案；请求选择其他档案或降级。

## 完整平台稿后结构编辑

接收单个平台的完整文章、本次风格说明、关系契约、权威内部底稿路径、主要目标效果、入口承诺和不可改变项，先读取 [relationship-and-voice.md](relationship-and-voice.md) 执行正向声音检查，再读取 [anti-template-editing.md](anti-template-editing.md) 执行结构与语言去模板化。

这一步发生在平台内容结构已经形成之后、格式和视觉处理之前。允许修复：

- 机械开头、假洞察和空泛转场；
- 按术语或固定模板切割的结构；
- 清单堆叠、重复总结和没有信息增量的段落；
- 均匀节奏、作者缺席、第一人称空壳和伪人类化；
- 匿名说明书、读者反应缺席、抽象概念悬空和不合语境的网络用语；
- 标题承诺已经偏离正文主线的语言问题；
- 相邻段落关系不成立、连接词暗示伪因果或伪递进，以及局部入口没有交接给全文主问题。
- 重点缺失、机械加粗、整段加粗，或强调位置与真实信息重量不一致。

不得把多个平台改成同一种结构，也不得接管 `broadcast` 已确定的目标效果、入口承诺和平台定位。

返回：

```text
发现的问题：位置 + 类型 + 影响
执行的修改：位置 + 修改目的
主动保留：自然准确或无需修改的部分
内容内核检查：
身份检查：
待确认项：
结论：通过 / 需修正后通过 / 因内容边界冲突停止
```

完整平台稿未通过时，不进入最终封面、正文视觉和平台格式处理。

## 平台格式与视觉后终检

接收已经完成封面、正文视觉和平台格式处理的最终平台稿及其内容形态。

检查：

- 主风格是否一致；
- 平台差异是否合理；
- 是否出现身份冒充或虚构经历；
- 场景语气是否失调；
- 说话位置、读者关系和对话距离是否在格式处理后仍然成立；
- 是否堆叠参照作者的独特口癖；
- 格式、图片位置、图注或元数据处理是否重新引入机械开头、空泛转场、重复总结和均匀节奏；
- 语义重点是否被正确保留，是否因平台渲染变成连续高亮、整段加粗或失去层级；
- 语言层调整是否导致事实或边界漂移。

返回问题位置、最小修改、主动保留和内容内核检查。只处理终端问题，不重新推翻已经通过的内容主线，也不把所有平台改成同一种结构。

## 冲突

按以下顺序处理：

```text
事实与内容边界
    ↓
场景严肃性
    ↓
用户明确风格要求
    ↓
个人默认风格
    ↓
平台偏好
```

风格与事实冲突时保留事实。

风格与平台结构冲突时保留平台结构，只在语言层寻找等价表达。

## 降级

| 情况 | 处理 |
|---|---|
| 用户空间不可访问 | 使用当前会话候选或内置默认，不声称已保存 |
| 没有默认个人档案 | 使用内置默认 |
| 指定参照未正式发布 | 使用对应通用类型并说明差异 |
| 材料不足以支撑第一人称 | 改为直接论述或可靠案例 |
| 风格检查可能改变事实 | 只报告问题，不自动重写该处 |
| 已经自然且准确 | 明确通过，不为显示工作量强行修改 |
