# 与广播的集成

## 职责

| 能力 | `writing-style` | `broadcast` |
|---|---|---|
| 收集和提炼风格 | 负责 | 不负责 |
| 管理档案和默认风格 | 负责 | 读取结果 |
| 场景语气 | 负责 | 提供话题、读者和风险 |
| 事实、观点和传播主线 | 不改变 | 负责 |
| 平台结构和形态 | 不决定 | 负责 |
| 语言层应用 | 负责 | 接收调整 |
| 最终验收 | 风格与身份 | 事实、传播和平台 |

## 写作前调用

`broadcast` 提供：

```text
内容内核：
主题：
目标读者：
内容目的：
风险：
目标平台与形态：
用户指定风格：
用户空间：
```

`writing-style` 返回：

```text
主风格及来源：
场景语气：
叙述视角：
读者关系：
用词与句式：
段落与节奏：
结构或叙事偏好：
应强化：
应抑制：
不可改变：
降级或未知：
```

没有个人默认档案时使用内置通用默认风格。

指定档案不存在时，不虚构档案；请求选择其他档案或降级。

## 成稿后调用

接收每个平台成稿及其内容形态。

检查：

- 主风格是否一致；
- 平台差异是否合理；
- 是否出现身份冒充或虚构经历；
- 场景语气是否失调；
- 是否堆叠参照作者的独特口癖；
- 语言层调整是否导致事实或边界漂移。

返回问题位置和最小修改，不把所有平台改成同一种结构。

## 冲突

按以下顺序处理：

```text
事实与内容边界
    ↓
场景严肃性
    ↓
用户明确风格要求
    ↓
个人默认风格
    ↓
平台偏好
```

风格与事实冲突时保留事实。

风格与平台结构冲突时保留平台结构，只在语言层寻找等价表达。

## 降级

| 情况 | 处理 |
|---|---|
| 用户空间不可访问 | 使用当前会话候选或内置默认，不声称已保存 |
| 没有默认个人档案 | 使用内置默认 |
| 指定参照未正式发布 | 使用对应通用类型并说明差异 |
| 材料不足以支撑第一人称 | 改为直接论述或可靠案例 |
| 风格检查可能改变事实 | 只报告问题，不自动重写该处 |
