# 去模板化编辑

面向中文大众长图文，识别并修正让文章显得机械生成的表达，同时保护事实、作者身份和平台语境。

## 目标与边界

目标是让结构服从真实问题，让语言重新出现具体对象、动作、判断和自然节奏。不要以欺骗 AI 检测器、降低检测分数或伪装作者身份为目标。

优先级固定：

1. 事实、观点、条件、例外、风险和未知不变。
2. 不新增作者没有表达过的经历、情绪、立场和第一手观察。
3. 保留主风格、场景语气和平台合理差异。
4. 只修正能够指出具体位置和影响的问题。
5. 已经自然准确的内容保持不变。

不要编辑引用原文、代码块、数据、链接、图片路径、Markdown 元数据和必须保持精确的术语。它们存在表达问题时只报告，不直接改写。

## 执行模式

- 检查：用户要求“只检查”“指出 AI 味”时，只报告问题，不改正文。
- 编辑：用户要求“去 AI 味”“改得自然”或指定文件修改时，执行最小修改并报告。
- 广播终检：由 `broadcast` 调用时，按基础长文编辑或平台稿终检范围执行，不接管传播主线和平台结构。

没有个人档案时使用内置通用默认风格。不得为了填补个人声纹而发明作者特征。

## 处理顺序

1. 锁定内容内核和作者真实拥有的经历。
2. 读取本次风格说明；没有时解析内置通用默认风格。
3. 按五类问题扫描全文，记录准确位置、原句、问题和影响。
4. 区分高置信问题、依赖语境的问题和应该保留的表达。
5. 依次执行：删除无信息内容、恢复具体对象、合并重复意思、调整局部节奏、校准作者与读者关系。
6. 完成一次二次审计，只修复第一轮修改新引入的问题，不反复重写直至“零模式”。
7. 回对内容内核、平台结构和身份边界。

## 问题清单

### 结构模板化

- S1 宏大通用开头：从“在当今时代”“随着技术不断发展”等任何主题都能套用的背景进入。
- S2 预告代替内容：先说“接下来深入探讨”“下面逐一分析”，却没有立即推进事实或判断。
- S3 小标题过度对称：标题数量、字数和句式刻意整齐，但真实论证关系并不平级。
- S4 章节复制同一模具：每节都按“定义—三点—总结”展开，内容轻重没有差异。
- S5 列表综合征：本可连续解释的内容被拆成大量三点、五点或“首先其次最后”。
- S6 标题后空转：标题下面先用一句话复述标题，再进入真正内容。
- S7 重复总结：段末、小节末和全文末连续复述同一结论。
- S8 机械升华：最后突然转向“未来可期”“值得共同期待”，来源没有对应行动或计划。

### 语言套话化

- L1 空泛转场：“值得注意的是”“需要强调的是”“从某种意义上说”没有承担真实逻辑关系。
- L2 假装深入：“本质上”“真正的问题是”“更深层次看”之后只是换词复述。
- L3 无对象判断：“实现了提升”“带来了赋能”“形成了闭环”没有说明谁做了什么、影响什么。
- L4 抽象名词堆叠：连续使用“价值、能力、体系、生态、维度、逻辑”等词，却没有动作或场景。
- L5 正确废话：句子普遍正确，但删掉后不损失任何事实、判断和理解。
- L6 同义改写循环：相邻句反复把同一结论换一种说法。
- L7 过度完整：为了显得全面，补入与主线弱相关的条件、维度和展望。
- L8 机械平衡：每个判断都立即接“当然”“与此同时”“也要看到”，把真实取舍磨平。
- L9 否定揭晓句滥用：反复使用“不是……而是……”“不只是……更是……”制造假冲突。
- L10 营销与宏大词：在观点分析中无依据地使用“颠覆、革命性、前所未有、必然趋势”。

### 节奏机械化

- R1 句长均匀：连续多句长度和结构相近，读起来像节拍器。
- R2 段长均匀：全文每段都保持相似行数，没有随信息轻重变化。
- R3 三项排比成瘾：大量观点都被压成三个短语或三个句子。
- R4 金句密度过高：每段都试图以可截图的判断句收尾，论证反而被切碎。
- R5 戏剧性碎句：连续使用“一句话。很重要。非常重要。”制造人为停顿。
- R6 疑问句流水线：连续自问自答只用于转场，没有真实疑问或信息增量。
- R7 标点风格失真：为了显得活泼突然堆叠破折号、括号、感叹号或省略号，与作者样文不符。

### 作者缺席

- A1 没有取舍：罗列所有可能角度，却不说明本文采用哪个判断及其条件。
- A2 没有对象感：不知道在对谁说话，也不知道读者为什么需要这一段。
- A3 无来源的全知语气：把推断写成确定事实，或者替行业、公众和未来统一发言。
- A4 血色中立：材料已经支持明确判断，文章仍用层层软化保持无意义中立。
- A5 借金句代替论证：一句有气势的话承担了本应展开的因果关系。
- A6 结论与作者脱节：结论来自模板常识，不来自本文事实、经历或推理。

### 伪人类化

- H1 虚构第一人称：新增“我曾经”“我身边有人”“最近我发现”等来源没有的经历。
- H2 虚构具体性：为了显得真实，擅自增加时间、地点、人物、数字和对话。
- H3 人工噪声：故意加入错别字、病句、重复词或不合语境的网络用语。
- H4 情绪表演：无材料支持地增加愤怒、兴奋、震惊、无奈或煽情。
- H5 口癖注入：批量加入“说白了”“你品”“懂的都懂”等并非作者稳定特征的表达。
- H6 粗暴口语化：把专业判断全部改成聊天短句，损失准确性和可信度。
- H7 模仿身份：复制参照作者的履历、固定开头、标志性句式或签名结构。

## 中文长图文误判边界

- 公众号短段落可能是移动端适配，不因段落短就判为机械碎句。
- 知乎编号论证可能服务检索和推理，不因使用编号就判为列表综合征。
- 技术文章重复术语可能为了准确，不要强行换同义词。
- 严肃说明保持中性是合理选择，不要强行加入观点、幽默和第一人称。
- 两三个平级事项本来就适合列表时保留列表，不为避免“三项”而增加或删除事实。
- 作者样文稳定使用的句式、标点和口语高于通用规则，除非它妨碍当前场景的准确性。
- 单个词不能独立证明 AI 痕迹；结合密度、结构和语境判断。

## 最小编辑方法

- 空泛开头：直接从来源中的问题、场景、结果或判断进入。
- 无对象判断：补回来源已经给出的主体、动作、对象和后果；来源没有时改成朴素表达，不编细节。
- 重复总结：保留信息最完整、位置最合适的一次，其余删除。
- 对称结构：按照问题之间的真实关系合并、拆分或取消小标题。
- 均匀节奏：只调整局部句段组合，让长度变化来自信息轻重，不随机打碎句子。
- 作者缺席：从已经确认的观点和材料中恢复取舍；没有支持时保留中性并标记待确认。
- 伪人类化：删除虚构内容，回到直接论述或可核验案例。

示例：

```text
前：值得注意的是，AI 正在以前所未有的速度重塑内容生态，这不仅是一场工具革命，更是一场认知革命。
后：AI 已经能批量生成文章、图片和视频，但生成内容与长期运行软件仍是两类工作。

前：本质上，真正重要的不是生成，而是生成之后能否持续负责。
后：软件交付后还要处理状态、数据、权限、故障和后续变更。

前：我最近和很多创业者聊过，大家都非常焦虑。
后：如果来源没有这些访谈，删除这句，直接说明已经确认的问题。
```

## 复核与输出

输出：

```text
使用的主风格与场景语气：
发现的问题：位置 + 编号 + 影响
执行的修改：位置 + 修改目的
主动保留：自然准确或属于平台合理差异的部分
内容内核检查：事实、观点、条件、例外和表达强度
身份检查：是否新增经历、情绪、口癖或具体事实
待确认项：只有作者能够决定的表达
结论：通过 / 需修正后通过 / 因内容边界冲突停止
```

验收：

- 每项修改都能对应到具体问题，不输出笼统的“已优化得更自然”。
- 自然成稿可以直接通过，不为显示工作量制造修改。
- 不要求所有模式归零；有表达价值且符合作者声纹的写法可以保留。
- 不报告或追逐 AI 检测分数。
- 第二次审计后仍可能改变事实或身份的修改一律撤回并报告。
