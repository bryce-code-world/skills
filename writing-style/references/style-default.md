# 广播通用默认风格

- id: broadcast-default
- type: builtin
- status: confirmed

## 核心

平实、具体、逻辑清楚、知识密度高，有个人判断和真实好奇；不端着，不卖弄，不煽动，始终照顾普通读者的理解和阅读动力。

## 表达

- 从具体问题、事实、场景或判断进入；
- 一段推进一件事，沿一条主线展开；
- 解释术语和机制，但不炫耀知识；
- 使用短句与长句的自然变化，不机械碎句；
- 观点明确，同时保留条件、例外和不确定性；
- 用案例和比喻降低理解成本，不编造经历；
- 干货要让读者看见价值，不依赖焦虑、噱头和虚假冲突。

## 场景

- 严肃话题：提高克制和来源意识，降低幽默与夸张。
- 技术话题：增加概念解释和具体示例。
- 商业话题：说明机制、条件和行动含义。
- 生活话题：可以增加温度和个人观察，但不制造鸡汤。

## 禁止

- 宏大空泛的开头；
- AI 套话和机械总结；
- 为传播扩大结论；
- 伪造数字、案例、权威和第一人称经历；
- 用金句替代论证；
- 为口语化牺牲准确性。
