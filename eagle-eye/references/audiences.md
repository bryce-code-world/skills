# 目标用户注意力模型

本文件定义“什么值得目标用户关注”。它不决定研究方向，也不参与事实真伪判断。

## 建立目标用户卡

正式研究前明确：

- 用户身份和对当前方向的已有认知；
- 正在作出的决定、要解决的问题或承受的风险；
- 通常接触信息的渠道；
- 什么变化会让他受益、受损、惊讶或需要行动。

用户明确描述目标读者时，以用户定义为准。只有用户未进一步限定时，才使用方向包声明的默认画像。

## 注意力维度

通过事实证据门禁后，每项按 0—5 分判断：

| 维度 | 判断问题 |
| --- | --- |
| 当前注意力 | 目标用户是否已经出现可验证的搜索、阅读、讨论或采用增长？ |
| 潜在注意力 | 权威变化是否尚未广泛扩散，但很可能影响目标用户？ |
| 直接关联 | 是否改变用户的利益、成本、风险、选择或行动？ |
| 决策时效 | 用户是否需要在当前时间窗内理解或判断？ |
| 认知缺口 | 现有传播是否遗漏用户真正需要理解的机制或限制？ |
| 扩散动力 | 是否存在实用收益、利益冲突、身份认同或可参与讨论的问题？ |

当前注意力和潜在注意力分别保留。不能用一个总热度掩盖二者，也不能让注意力评分绕过原始来源门禁。

### 开发者

- 关注：接口、能力、许可、成本、兼容性、部署、维护和真实故障；
- 决策：是否试用、迁移、集成、替换或规避；
- 渠道基线：官方文档与 Release、GitHub、包注册表、Hacker News、V2EX、开发者社区。

### 产品经理与创业者

- 关注：用户需求、产品入口、价格、可替代性、商业机会和落地约束；
- 决策：是否立项、调整路线、选择供应商或改变商业模式；
- 渠道基线：产品发布页、官方定价、创始人原文、行业媒体、产品与创业社区、搜索趋势。

### 企业管理者

- 关注：组织效率、采购、战略、成本、合规、数据和供应商风险；
- 决策：是否采购、试点、扩大使用、调整组织或建立治理；
- 渠道基线：企业公告、财报与电话会、客户案例、监管文件、专业媒体和企业社交渠道。

### 投资与产业人群

- 关注：投入规模、收入、市场结构、供应链、竞争壁垒和兑现周期；
- 决策：如何判断公司、赛道、产业链位置和风险；
- 渠道基线：监管披露、财报、交易所公告、产业媒体、分析师材料和关键供应链信号。

### 普通科技读者

- 关注：日常影响、认知变化、隐私、安全、就业、价格和公共讨论；
- 决策：是否使用、信任、付费、规避或参与讨论；
- 渠道基线：搜索趋势、主流媒体、Wikimedia、YouTube、B站和公开社区平台。

## 信号归一与降噪

不同平台用户结构不同，原始互动量不能直接相加：

1. 只在同一来源、相近时间窗和同类事件内比较增速或相对位置；
2. 同一报道的转载先聚类去重，再计算独立扩散；
3. 对机器人流量、营销投放、单平台尖峰、旧闻翻炒和争议诱导降权；
4. 平台信号只代表其用户样本，不外推为全部目标用户；
5. 没有目标用户信号时不能声称“已经形成热点”，但权威变化和直接影响充分时可以标记为潜在热点。

## 使用结果

注意力模型用于候选排序，并把候选标记为“当前热点”“潜在热点”或“不匹配”。随后仍需通过可写性评分和选题角度验证。

画像、单项分数、权重调整和原始平台数值默认只保留在内部判断中，不写入每日热点文件。
