# 知识时效与变化

在主题依赖当前主流、最新实践、现行工具，或从已有动态课程恢复时读取本文件。

知识时效用于判断学习对象和学习路径现在是否仍然适用。它不评价学习者，也不是第十个学习阶段。

## 变化等级

按具体学习范围判断，不给整个领域永久贴标签。

| 等级 | 典型内容 | 默认处理 |
| --- | --- | --- |
| 稳定基础 | 数学原理、长期稳定的概念和基础机制 | 不强制频繁联网，按普通课程推进 |
| 缓慢演进 | 成熟领域的方法、标准和工程实践 | 材料陈旧、长期续学或要求当前口径时核验 |
| 高速变化 | AI 模型、框架、工具、产品能力和当前工程范式 | 涉及当前主流时，在开始和续学前核验 |
| 前沿待定 | 新兴、争议中或证据不足的方向 | 核验一手来源，保留竞争观点和不确定性 |

同一主题可以包含多个等级。例如，Transformer 的核心机制可以是稳定基础，当前 Agent 工具链可以是高速变化。

## 内容角色

动态学习地图使用以下角色：

- **基础不变量**：工具变化后仍支撑理解的原理与判断框架。
- **当前主流**：在快照日期仍普遍采用，并直接影响当前目标的路径。
- **工具与实现**：具体模型、框架、API、技巧和版本行为。
- **过渡或旧范式**：已被替代，但仍服务于历史理解、旧系统维护或演进研究。
- **前沿待验证**：尚未形成稳定共识，只作为观察、比较或实验对象。

## 时效校验门禁

同时满足以下条件时，开始或续学前必须联网核验：

1. 学习范围属于高速变化或前沿待定。
2. 用户目标包含当前主流、最新实践、现行工具、当前最佳路径或同等含义。

优先使用当前可访问的一手资料、官方文档、原始论文、标准、版本说明和项目仓库。需要二手资料时，区分来源事实、行业判断和 Agent 推断。

无法联网或缺少关键来源时：

- 继续稳定基础和不依赖当前状态的内容。
- 把动态路径标记为“当前未验证”。
- 不声称课程、结论、工具选择或优先级是最新的。

## 知识快照

快照至少记录：

```text
快照日期
学习范围
变化等级
核验来源
当前主流判断
争议或无法确认的部分
下次复核条件或日期
```

新快照形成后，对原路径逐项标记：

- 保留：内容和顺序仍适用。
- 提前或后移：内容仍有价值，但优先级变化。
- 暂缓：证据不足，暂不作为必学路径。
- 退役：对当前目标不再必要，只保留历史状态和原因。
- 新增：新范式或新前置已经影响当前目标。

不要删除旧内容或已有证据。当前实践目标可以跳过退役内容；维护旧系统、研究演进或历史理解目标可以保留。

## 证据的时间边界

高速变化知识的证据增加：形成日期、适用范围、依赖版本或范式、时效状态和下次复核条件。

时效状态使用：当前有效、部分失效、已被替代、当前未验证、需要复核。

时效变化只调整证据的适用范围，不把曾经真实形成的证据改写成从未发生，也不让工具更新自动抹除稳定原理证据。
