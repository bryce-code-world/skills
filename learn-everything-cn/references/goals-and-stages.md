# 学习终点与阶段

在定向、诊断起点、调整课程或判断完成时读取本文件。

## 五级学习终点

终点描述本次学习希望达到的结果，不是对学习者的能力评级。

| 终点 | 目标 | 最低完成证据 |
| --- | --- | --- |
| 认识 | 能辨认概念，知道用途和典型场景 | 识别概念并说明基本用途 |
| 理解 | 能解释机制、关系、边界和典型例子 | 独立解释，并处理一个边界或反例 |
| 掌握 | 能脱离材料独立应用，并处理变化场景 | 独立应用证据和迁移证据 |
| 熟练 | 能在多次真实或高仿真任务中稳定完成 | 实践证据和跨时间或多任务稳定证据 |
| 创造 | 能评价、组合、改进或形成新产物 | 原创产物以及评价或验证依据 |

优先从用户表达推断终点：

- “了解、认识、知道是什么”对应认识。
- “讲懂、理解原理、说明为什么”对应理解。
- “学会使用、能够独立完成”对应掌握。
- “熟练、深入实践、工作中稳定使用”对应熟练。
- “研究、设计、改进、形成自己的方法”对应创造。

意图明确时说明推断后继续。不同终点会显著改变课程，而用户意图仍不明确时，只询问一个关键问题。

## 九阶段引擎

终点决定走到哪里，阶段决定当前怎样前进。

| 阶段 | 核心问题 | 退出证据 |
| --- | --- | --- |
| 0. 定向 | 为什么学，学到什么程度？ | 终点、范围、变化等级和主题目录明确 |
| 1. 探底 | 已经知道什么，当前模型是什么？ | 起点、前置缺口和可能误解明确 |
| 2. 建构 | 这个知识是什么？ | 能识别概念并说明基本用途 |
| 3. 校准 | 当前理解是否符合实际？ | 能解释机制、关系、边界和反例 |
| 4. 应用 | 能否在有支持时使用？ | 能完成典型任务并解释关键判断 |
| 5. 迁移 | 换一个场景还能否使用？ | 能独立应用并处理变化 |
| 6. 实战 | 能否在真实约束中完成？ | 形成可检查的实际产物 |
| 7. 稳定 | 能否多次稳定完成？ | 多次表现稳定，支持基本退出 |
| 8. 创造 | 能否评价、组合和改进？ | 形成有理由、有验证的新方案或产物 |

最低完成阶段：

```text
认识  → 阶段 2
理解  → 阶段 3
掌握  → 阶段 5
熟练  → 阶段 7
创造  → 阶段 8
```

## 路由规则

- 用当前可观察证据选择起点，不默认从阶段 0 重新教起。
- 诊断证明已有基础时，从后续阶段开始。
- 证据失败时，退回产生缺口的阶段，不要求整门课程重来。
- 用户提高终点时，在现有路径后增加必要阶段，不清空已有证据。
- 用户降低终点时，重新判断现有证据是否已满足完成条件。
- 用户停止时，记录为完成、暂停或未达到原终点中的真实状态。
