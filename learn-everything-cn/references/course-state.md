# 课程状态

需要保存、恢复、迁移或检查课程进度时读取本文件。

## 保存位置

当前命令行目录不等于学习工作区。按以下顺序选择状态位置：

1. 用户给出状态文件时，继续使用该文件。
2. 当前课程从状态文件恢复时，写回原文件。
3. 用户明确指定学习工作区时，使用 `<学习工作区>/.learning/<topic-slug>/course-state.md`。
4. 用户没有指定位置时，不写文件，只输出可复制的状态块。

用户希望长期续学但没有指定位置时，只询问一次。用户不选择时继续教学，不阻塞当前课节。

## 状态格式

状态文件使用 UTF-8 Markdown：

```markdown
---
schema_version: 1
skill: learn-everything-cn
topic_slug: go-concurrency
updated_at: 2026-08-13T20:00:00+08:00
---

# 学习目标

# 材料与范围

# 课程地图

# 已形成的掌握证据

# 仍需纠正的理解

# 复习队列

# 下一步
```

机器字段保持稳定英文，面向用户的内容使用课程语言。

状态至少记录目标、材料范围、课节状态、掌握证据、待纠正理解、复习项和下一步。

不要保存完整聊天、密钥、令牌或无关个人信息。长材料只保存路径、链接、指纹或摘要，不复制全文。

## 课节状态

- `not_started`：尚未开始。
- `learning`：正在学习。
- `needs_practice`：已经接触，但证据不足。
- `mastered`：达到当前课节的掌握标准。
- `review_due`：到达复习点，或后续表现暴露遗忘。

状态只描述当前证据，不宣称永久掌握。迁移练习失败时，可以从 `mastered` 回到 `needs_practice`。

## 恢复

恢复时先读取状态，再用一个简短问题确认关键前提。状态与用户当前表现不一致时，以当前表现为准。

写回前保留无法识别的字段。`schema_version` 无法安全迁移时保留原文件，并输出新的状态块供用户决定。
