# 学习证据与门禁

判断继续、升级、完成、复习或降低结论时读取本文件。

## 证据类型

| 类型 | 能证明什么 |
| --- | --- |
| 识别证据 | 能辨认概念、用途和典型场景 |
| 解释证据 | 能用自己的话说明机制、关系和边界 |
| 应用证据 | 能完成典型任务并解释关键判断 |
| 迁移证据 | 能在变化后的新场景中独立应用 |
| 实践证据 | 能在真实约束下形成可检查产物 |
| 稳定证据 | 间隔一段时间或更换任务后仍能完成 |
| 创造证据 | 能评价、组合、改进或形成有效新方案 |

证据不能随意替代。会复述不能替代应用，模拟不能冒充真实实践，一次成功不能证明熟练。

## 证据来源

每项证据标记真实来源：

```text
语言表达
纸面推演
模拟环境
受控实验
真实任务
外部结果
```

明确区分已经形成的证据和仍缺少的真实体验。

## 证据状态

| 状态 | 含义 |
| --- | --- |
| 未验证 | 学过或看过，但没有可检查表现 |
| 初步形成 | 在当前示例或有支持条件下成功 |
| 独立成立 | 脱离提示后仍能完成 |
| 稳定成立 | 跨时间、跨场景或多次任务仍然成立 |
| 需要复核 | 到达复习点，或后续表现暴露遗忘 |

新证据可以提高或降低原判断。后续失败时降低对应证据状态，不保留已经失效的高等级结论。

高变化知识还要标记形成日期、适用范围和时效状态。来源真实不等于结论永久有效。

## 证据、待验证与误解

三类状态不能混用：

- **已形成证据**：学习者已经产生可观察表现，并注明条件、来源和强度。
- **已讲解待验证**：内容已经解释或纠正，但学习者尚未用表现证明理解。
- **当前仍存在的误解**：最新表现仍显示错误模型、错误边界或错误关系。

讲过不等于形成证据。

误解被讲清但尚未验证时，移入“已讲解待验证”。

学习者通过表现完成纠正时，移出误解区并登记证据。同一内容不能同时作为当前误解和已成立证据重复保存。

## 最小门禁

```text
认识 → 识别证据
理解 → 解释证据 + 边界或反例
掌握 → 独立应用证据 + 迁移证据
熟练 → 实践证据 + 多次稳定证据
创造 → 原创产物 + 评价或验证依据
```

简单主题只收集足以判断当前终点的最小证据。

## 登记规则

- 记录可观察表现、条件、支持强度、来源和状态。
- 不把“看懂了”“感觉会了”或普通回答登记为掌握。
- 有产物但不能解释关键判断时，不判定掌握。
- 用户拒绝验证时把内容保留在“已讲解待验证”，不登记为已形成证据。
- 模拟成功只登记为模拟证据，并指出仍缺的真实实践。
- 用户暂停时记录真实状态，不把暂停写成完成。
- 单次回答产生的证据候选先留在会话内；到达持久检查点且能够独立复用时再合并登记。
