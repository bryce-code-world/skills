# 方法选择与支持强度

确定当前阶段和证据缺口后读取本文件。

## 选择顺序

按以下顺序选择本学习单元的主要方法：

1. 确认当前内容和路径已通过所需的时效校验。
2. 判断当前阶段。
3. 找到阻碍晋级的最小证据缺口。
4. 判断内容属于概念、关系、流程、技能、判断还是实践。
5. 确认真实操作条件和授权。
6. 考虑用户当前可投入的时间与精力。
7. 选择足以补上缺口的最小方法。

一次学习单元只选择一种主要方法。失败后先诊断原因，再更换方法或调整支持强度。

## 五级支持强度

支持强度表示当前知识点需要多少帮助，不表示学习者的整体能力。

| 等级 | AI 与学习者的关系 |
| --- | --- |
| 5. 完整示范 | AI 展示完整过程，并解释关键判断 |
| 4. 共同完成 | AI 建立框架，学习者完成部分步骤 |
| 3. 提示引导 | 学习者主做，AI 只给渐进提示 |
| 2. 独立完成 | 学习者独立完成，AI 在完成后反馈 |
| 1. 教回与创造 | 学习者解释、评价或设计，AI 负责追问和检验 |

调整规则：

- 根据诊断选择起点，不默认从完整示范开始。
- 当前任务成功后降低一级支持。
- 连续失败、挑战过大或缺少前置时提高一级支持。
- 一次只提高一级支持，或只缩小一次任务跨度。
- 困难转为挫败时，给出最小必要解释。
- 按知识点分别记录支持强度。
