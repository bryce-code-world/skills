# 中文学习工作区与状态

正式建课、创建或升级目录、保存进度、暂停或续学时读取本文件。

## 父目录门禁

每个正式学习主题必须由用户指定学习内容父目录。

不得默认使用当前项目、用户主目录、上一次课程目录、`.learning`、`learn` 或其他隐藏目录。

没有父目录时，可以澄清目标，但不得正式建课或写入学习资产。只询问一个关键问题：学习内容父目录放在哪里？

用户指定父目录并正式建课，或提供现有主题目录并要求续学，视为授权 Skill 在该主题目录内维护课程状态。检查点更新不需要重复询问；该授权不扩展到主题目录外的真实项目或外部系统。

## 中文主题目录

实际路径为：

```text
<用户指定父目录>/<中文主题目录>/
```

生成目录名时：

- 优先使用自然、简短、可辨认的中文名称。
- 技术专名没有合适译名时保留，例如 `Go并发`、`Transformer位置编码`。
- 不使用拼音或英文 slug 作为面向用户的目录名。
- 替换操作系统不允许的字符。
- 创建前说明最终绝对路径。
- 同名目录存在时先判断是否为同一主题，不静默覆盖或混入。
- 建课后不因目标细化自动重命名。

## 最小工作区

### 微型主题

单个概念、一次或少量会话完成的认识与理解目标使用单文件：

```text
注意力机制/
└── 学习记录.md
```

使用 [micro-learning-record.md](../assets/templates/micro-learning-record.md)。动态主题把时效快照写进同一文件。

### 标准主题

多课节、练习或迁移验证使用：

```text
Go通道/
├── 学习地图.md
├── 学习进度.md
├── 学习材料/
└── 练习与验证/
```

材料和练习按逻辑学习单元组织。同一单元中的连续追问、纠错和验证默认更新同一份文件，不按对话轮次创建新资产。

使用 [learning-map.md](../assets/templates/learning-map.md) 和 [learning-progress.md](../assets/templates/learning-progress.md)。只创建当前会实际使用的目录。

### 深度主题

系统学习、熟练、真实项目或创造目标按需增加：

```text
Go并发/
├── 学习地图.md
├── 学习进度.md
├── 学习材料/
├── 课程记录/
├── 练习与验证/
├── 实践项目/
└── 复习与评估/
```

先创建最小结构。进入实战、长期复习或创造时，再增加对应目录。

只有多次路径变更、多个竞争范式或长期追踪确有需要时，才创建 `变化追踪.md`。

## 状态模型

单文件和多文件使用同一组含义：

```text
主题、学习动机、终点深度、内容范围、主题规模
变化等级、时效目标、知识快照日期与来源、路径时效状态
当前阶段、当前学习单元、各知识点支持强度
证据及其来源、状态和时间边界
已讲解待验证、当前仍存在的误解、真实实践缺口、复习队列
下次时效复核条件或日期、下一步
```

简单主题把字段压缩在 `学习记录.md`。复杂主题再拆到学习地图、进度、练习和项目目录。

## 会话状态与持久检查点

连续教学先更新会话内暂存状态。暂存状态包含当前单元的回答、纠错、提示、证据候选和支持调整，不要求每次都写入工作区。

出现以下检查点时，才把暂存变化合并写入工作区：

- 新主题正式建立。
- 终点、范围、材料、保存路径或知识快照改变。
- 路径发生保留、重排、暂缓、退役或新增。
- 学习单元完成，或进入新阶段。
- 重要证据已经能够独立复用，或被推翻、降低。
- 完成真实任务或实际产物。
- 用户暂停、结束、要求跨会话继续或明确要求保存。
- 宿主上下文即将丢失，不保存会造成明显恢复风险。

以下情况单独发生时，不是持久检查点：

- 单个正确、错误或部分正确的回答。
- 支持强度变化。
- 进入下一道微问题或补充普通解释。
- 产生尚不能独立复用的证据候选。

## 学习单元边界

进入下一问前，先用一句话写出当前单元正在验证的主要对象或不变量。

再按以下规则判断下一问：

- 仍然验证同一主要对象或不变量：留在当前单元。
- 只是完成当前目标所需的最小前置澄清：留在当前单元。
- 转向新的拓扑、配置、管理对象、独立可复用证据或不同不变量：先完成当前单元并形成检查点，再开始新单元。
- 当前内容已经无法用一句话概括：立即拆分为多个单元。

边界按学习语义判断，不按对话轮次、回复长度或文件数量判断。前置知识可以服务当前单元，但不能借“补充说明”无限吞并后续概念。

检查点写入遵循以下规则：

1. 读取已有文件。
2. 合并自上次检查点以来的变化，一次更新当前权威状态。
3. 复用当前逻辑单元的材料和练习文件，不把连续对话拆成多个文件。
4. “已形成证据”只保留可观察表现。
5. 讲过但未验证的内容放入“已讲解待验证”。
6. “当前仍存在的误解”只保留未纠正问题。
7. 误解被讲清但未验证时，移入“已讲解待验证”。通过表现纠正时，移出误解区并按证据强度登记。
8. 同一内容不在多个状态区重复保存。
9. 不保存完整聊天、凭据、无关个人信息或内部工具流水。
10. 当前单元与已完成单元不得使用同一标识；已完成单元不得继续标为当前。
11. 学习地图和学习进度中的当前单元名称必须一致。
12. 需要编号时使用下一个未占用编号；原结构没有稳定编号体系时不强行补号。

恢复后发现上述冲突时，修复写入是进入新教学前的阻断门禁。

当前单元已经存在足够完成证据，而且下一步转向新的主要对象时，直接形成检查点。不等待用户再次声明“这一节完成了”。

无法写入时说明阻塞并停止，不带着冲突继续新单元。

## 续学

只恢复当前版本生成的主题目录、`学习记录.md`、`学习地图.md` 或 `学习进度.md`，不扫描和迁移其他课程格式。

恢复时：

1. 读取已有状态、原定终点、快照、证据和下一步。
2. 判断动态路径是否到达复核条件。
3. 需要时先核验现状并重排路径。
4. 用一个最小问题验证学习者的关键前提。
5. 以当前表现校准状态。
6. 继续有效路径或调整阶段。

第 1 步是续学硬门禁。用户已经给出可访问的主题目录或状态文件时，不得只根据请求中的概述开始讲解。读取失败时说明缺失范围，并只问一个恢复所需的问题。

标准或深度主题恢复时，学习地图和学习进度共同构成当前权威状态，必须分别读取。部分读取、乱码或读取失败都不算完成恢复。

Windows 读取中文 Markdown 时显式使用 UTF-8。

一次读取一个文件，避免用复杂引号或命令分隔符拼接多个文件。失败后先重试该文件，再决定是否能够恢复。

读取完成后立即执行状态一致性检查和学习单元边界检查。检查或必要修复尚未完成时，不开始新单元讲解。

固定执行顺序：

1. 提取当前单元标识和名称。
2. 与已完成单元比较。
3. 判断当前证据是否满足目标。
4. 必要时先写入修复，再开始新教学。

例如，“已完成单元 4”和“当前单元 4”同时存在时，先使用下一个未占用标识修复当前单元。

写入前先读取现有文件。保留与当前结构不冲突的未知字段；恢复后的日常交互继续使用会话内暂存状态，直到下一个持久检查点。

## 材料与外部产物

- 小型材料在用户授权后保存到学习工作区。
- 大文件、仓库、网页和外部项目默认只保存路径、链接、指纹和必要摘要。
- 不复制长篇受版权保护材料或项目外敏感内容。
- 真实产物位于其他项目时，只在学习工作区记录引用和学习证据。
