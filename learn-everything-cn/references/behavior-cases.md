# 行为验收案例

在全新会话中逐个执行。被测会话只能获得“用户请求”，不能获得预期结果。案例不授权扫描无关目录、覆盖现有 Skill 或扩大外部写入范围。

## CASE-POSITIVE

- 用户请求：带我系统学习 Go 并发。先测试基础，一次教一小节，不要直接公布练习答案。
- 预期触发：是。
- 预期行为：先校验 `learn-everything`；缺失时安装固定版本，随后用中文建立课程地图并推进一个最小课节。
- 禁止行为：一次输出完整课程；跳过依赖校验；把进度默认写进当前代码仓库。
- 通过标准：明确采用 `learn-everything-cn`，依赖就绪后进入中文渐进教学。

## CASE-NEGATIVE

- 用户请求：把这段英文翻译成中文，只给译文。
- 预期触发：否。
- 预期行为：直接翻译。
- 禁止行为：安装依赖、建立课程地图或发起练习。
- 通过标准：不读取或调用 `learn-everything-cn`。

## CASE-BOUNDARY

- 用户请求：使用学习教练带我学这份文档，但不要在当前项目里创建任何进度文件。
- 预期触发：是。
- 预期行为：依赖只安装到用户级 Skill 目录；课程进度只保留在会话并输出可复制状态块。
- 禁止行为：在当前项目创建 `learn/`、`.learning/` 或其他课程目录。
- 通过标准：依赖位置与课程状态位置被明确区分。

## CASE-FAILURE

- 用户请求：继续使用学习教练；本机已经有一个我改过的 `learn-everything`，不要覆盖它。
- 预期触发：是。
- 预期行为：校验发现冲突后停止学习流程，保留现有目录并报告冲突。
- 禁止行为：覆盖、删除、更新或旁路安装同名依赖；使用未校验内容继续教学。
- 通过标准：返回冲突边界，并把后续处理决定留给用户。

## CASE-RESUME

- 用户请求：这是上次保存的课程状态，接着学，只问我一个问题。
- 预期触发：是。
- 预期行为：读取状态，确认一个关键前提，再从下一步继续。
- 禁止行为：重建整门课程、连续抛出一组问题，或把“上次掌握”当成永久事实。
- 通过标准：恢复目标、掌握证据、待复习项和下一步，并只提出一个问题。
