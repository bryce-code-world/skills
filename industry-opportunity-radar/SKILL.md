# 产业机会雷达

## 目标

帮助个人持续判断：哪些产业方向值得投入，普通人从哪里进入，当前最关键的未知是什么，以及应继续、聚焦、观察、调整、暂停还是放弃。

本 Skill 是个人决策支持工具，不是企业情报平台、行业排名器或金融产品推荐器。它不替用户辞职、借贷、重仓、自动交易或联系客户。

## 开始前的边界

1. 必须使用用户明确指定的持久化工作目录。目录未指定时只问一个问题：“请指定用于持续保存方向研究进度、资料和结论的工作目录。”不得猜测路径，也不得把资料写入 Skill 目录。
2. 进入工作目录后，先读取根控制入口；没有入口时只创建当前阶段需要的最小入口，不预建完整目录树、空模板或数据库。
3. 每次只推进一个模式和一个明确决策点。默认把结果写回根控制入口或当前方向记录，只有需要独立维护时才拆分文件。
4. 个人收入、资产、家庭、客户和身份信息只读取完成匹配所需的最小范围，不写入公开搜索词或外部服务。

## 工作模式

按当前任务选择一个模式，不在同一轮同时扫描、定方向和执行实验：

| 模式 | 目的 | 主要结果 |
| --- | --- | --- |
| 建立基线 | 记录目标、约束、能力、资源和风险边界 | 个人基线与下一步 |
| 扫描 | 维护候选方向，不做确定排名 | 候选方向及初筛理由 |
| 研究 | 建立一个方向的边界、价值链、利润池和证据 | 方向研究记录 |
| 匹配 | 判断个人能力、客户入口、时间和资金是否匹配 | 个人匹配与缺口 |
| 机会下钻 | 从方向进入具体客户、流程和问题 | 机会卡片 |
| 验证 | 用最低成本验证一个关键未知 | 实验契约与结果 |
| 决策 | 形成阶段性处理决定 | 决策记录与回退条件 |
| 监控 | 追踪会改变判断的信号 | 信号变化与复查建议 |
| 复盘 | 拆分方向、机会、方案、执行和时机的原因 | 假设与状态更新 |

## 最小研究闭环

### 1. 先写研究任务

在根控制入口或当前方向记录中维护：要支持的决策、方向边界、地域与时间范围、研究深度、关键未知和停止条件。

### 2. 再建证据链

对会改变决策的判断记录：证据编号、内容性质、来源和时间、适用范围、支持或反驳方向、独立性、局限以及关联假设。

- 区分用户事实、一手事实、二手分析、市场信号、AI 推断和未验证假设；
- 关键事实优先定位原始来源；搜索摘要、模型转述和网页片段只能当线索；
- 来源冲突并列保留，不方便时不选数字；
- “没有竞争者”“客户不会买”等否定判断要主动搜索反例；
- 无法核验就写“无法核验”及其影响，不用精确数字补空白；
- 不规定固定来源数量，以关键判断是否得到足够核验为准。

### 3. 只展开会改变决策的分析

需要时才补充客户原声、付费和采购行为、直接与间接竞品、人工流程、内部自建、维持现状、商业化阶段，以及“技术变化 → 客户结果 → 经济结果 → 优势持续性”的传导链。技术先进但不能传导到客户和经济结果时，不认定为商业机会。

### 4. 用实验替代预测

每个重点机会先写清验证问题、最小动作、对象、时间上限、成本上限、成功信号、失败信号、实际结果和下一步。优先验证真实问题、真实流程、试用或付费承诺、可量化结果和个人交付成本。

### 5. 决策前做最小自检

确认方向范围清楚；关键事实已核验或明确未知；存在至少一个反方解释；有客户行为信号或明确缺口；相关时考虑人工、内部自建和维持现状；下一步和停止条件具体。输出研究完备度：`可决策`、`带疑虑可决策` 或 `证据不足`。

阶段决定只能是条件化建议，最终放行权属于用户：继续、聚焦、观察、调整、暂停或放弃。新事实出现时，只回退受影响的假设和状态。

## 工作目录按需沉淀

根控制入口至少记录：当前目标、方向和状态、权威资料、阻塞项、当前实验、下一步、最近复盘时间和下次复盘条件。

按阶段创建真实需要的内容：

- 扫描候选方向时创建候选池或扫描记录；
- 进入深度研究时创建方向记录和证据账本；
- 形成机会时创建机会卡片；
- 开始实验时创建实验记录；
- 形成决策或复盘时创建对应记录；
- 确有持续变化需要追踪时创建信号记录。

不要默认生成周报、长篇行业报告、企业驾驶舱、固定评分、多智能体流程或完整目录树。

## 安全与外部状态

- 研究、资料和结论不自动获得执行授权；
- 联网时区分已检索、来源声称和已核验；
- 外部登录、写入、购买、投资、发消息和联系客户必须获得当次明确授权；
- 遇到资料冲突、目录不可读、证据不足或个人风险边界不明时，保留现状并明确阻塞，不编造确定结论。
